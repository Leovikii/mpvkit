# v0.1.2 实施与交接

> 历史记录：当前接手请读[开发基线](../current.md)，旧目录、兼容和安装包记录不是执行要求。

更新：2026-10-22。状态：本机实现与本轮隔离验证完成。用户已授权实现及前后端交互测试；音量步长确定为 10，退出续播为默认配置，不提供 GUI 开关。Windows x64，沿用 Tauri 2、React、Mantine 与 Rust，不升级工具链、不新增运行依赖。

## 已实现范围

- 首次引导合并为 **安装播放器 → 播放设置 → 添加到打开方式 → 状态页**。核心 MPV 与折叠的播放增强分组；增强含 uosc、thumbfast、霞鹜文楷屏幕阅读版。
- 安装页统一展示目录。默认目录不额外确认；高级选项收纳自定义目录、外部 MPV、替换已有文件和来源详情。只有实际切换目录才预览确认。切换不搬移文件；未应用路径/外部播放器草稿不沿用旧就绪状态，活动任务禁止编辑。
- 空格播放/暂停，回车全屏，左右精确跳转 5 秒，上下音量 ±10。关闭 MPV 内建键位，移除 Alt+1/2/3、Alt+s、F6。鼠标空白处单击暂停、双击全屏、右键菜单；菜单内方向键优先导航。
- 播放器菜单提供轨道、列表、章节、画质及保存档位、截图等动作，无额外全局单键；不展示可能绕过组件归属的 uosc 自更新入口。复用 uosc 倍速控件：拖动/滚动调速、右键恢复 1 倍。长按右方向键及组合调速暂缓。
- 默认 video-sync=audio、interpolation=no；不固定刷新率、不按 GPU 型号承诺性能、不引入无必要的 profiles.conf。[高刷调查](evidence/2026-10-22-display-sync.md)记录当前构建与上游问题；多屏高刷性能矩阵仍需设备验收。
- 默认退出时记录播放位置并在下次打开同一文件时续播。仅保存 start；记录放在配置目录的 watch_later/mpvkit-position，避免读取旧版手动保存的音量/速度等记录。不显示开关或清理记录 UI；用户可以在 user.conf 同时写 save-position-on-quit=no 与 resume-playback=no 停止保存和恢复。旧记录不删除；普通播放列表“下一项”不承诺保存位置。
- 播放设置的高级选项增加结束行为（默认关闭播放器，可保留窗口）与截图（默认 Pictures/MpvKit，PNG，不含字幕；可改目录、JPEG、含字幕）。目录由 MPV 在实际截图时创建，失败在播放器提示。路径按 MPV 原生定长字符串编码，拒绝控制字符和不安全路径。截图从菜单进入，不增单键。
- LXGW WenKai Screen v1.530 完整非等宽字体作为受管理增强组件，固定官方来源、版本、SHA-256 和 OFL 原文。存放配置目录 fonts/LXGWWenKaiScreen.ttf，sub-font 使用内部 family 名。保留 ASS 样式、系统/内嵌字体优先级，不安装系统字体、不改变应用字体。[字体来源和选择证据](evidence/2026-10-22-font-fallback.md)。

## 数据与迁移

Settings schemaVersion 提升至 3，旧版 1/2 可读取，写入时迁移，原有 overrides/语言/档位保留。新增播放字段 keepOpen、screenshotDirectory、screenshotFormat、screenshotSubtitles；续播和最小键位是生成默认值，不增加结构化开关。user.conf 仍最后加载。

现有已完成安装继续进入状态页。旧清单未登记 subtitle-font 时不因缺字体重新引导；组件更新纳入字体后按归属校验，缺失可修复、用户修改拒绝覆盖。旧平铺布局保持。更新应用本体不偷偷写播放器文件；通过组件更新或设置保存的具体预览应用新生成配置。目录切换、下载、部署仍是独立事务。

不改真实默认应用、注册表、用户字体或私人配置。保持 v0.1.1 的预览、过期校验、冲突保护、备份与恢复边界。项目没有获得本版本的提交、推送或发布授权。

## 验证与交付

已通过：常规后端 64 项、真实四组件解包部署 1 项、双语 2 项、原生用例 7 项分次通过，截图失败目标保留补测通过；格式、Clippy、前端、Debug/Release/NSIS 构建及许可清单核对通过。普通后端 6 项显式真实入口仍默认忽略，其中归档入口单独运行；其他入口不冒称本轮已重跑。详情与产物摘要见[实现验证](evidence/2026-10-22-implementation.md)。

原生入口 scripts/native-v012.test.mjs 覆盖三步安装、取消、目录草稿失效、旧布局/外部播放器、迁移、重启、损坏修复、维护、Mica、主题、键盘弹窗及保存失败；新增真实 MPV 检查最小键位、菜单方向键优先级、位置续播且不恢复旧音量/速度、user.conf 覆盖、PNG/JPEG 截图和字体摘要。

下一任务：用户复查 0.1.2 的安装与播放体验；按可用设备补齐下述验收。没有待实现的本轮必做功能。

未验收：实体 60 Hz/高刷切屏的掉帧、HDR、功耗矩阵，干净系统安装/卸载与旧 Windows；MPV 聚合构建、uosc 的完整来源/许可适用审查仍待完成。releaseReady=false；构建和隔离测试不等于全部产品验收。
