# v0.1.9 实施与交接

更新：2026-10-27。用户已授权实施；起点为 v0.1.8 的 63945b3。继续遵守无 CI、无历史开发版兼容/迁移、无安装包约束；只构建单 EXE / ELF。

## 本版决定

- 媒体打开方式交给系统 MPV 包维护；删除 MpvKit 专属注册、注销、状态、意图、恢复、IPC 与对应测试。配置保存、增强安装及卸载只处理自身文件事务。
- 设置状态移除 integrationEnabled，不读旧格式、不做迁移，不清理实际旧注册表或 desktop 文件；普通测试从新隔离根开始。
- “设置默认应用”是打开系统设置的普通按钮，放在顶部 MPV 核心管理区域，独立于高级选项与配置保存，核心安装后可用。由用户在系统选择 MPV，不自动更改默认应用。
- 保留播放期配置保存 helper、手改/过期/失败恢复保护，以及 Linux 管理器自身桌面入口和图标；删除专属媒体入口资产。
- 产品与独立预览同步更新；源码版本进入 0.1.9。

## 实施状态

已完成两端媒体登记代码、UI、状态与 IPC 删除，保留文件事务及播放期保存 helper。产品与离线预览的默认应用按钮均移到 MPV 核心行；核心缺失禁用，安装核心后无需增强即可使用。Linux 管理器自身桌面入口保留，Exec 转义及保护测试随实现移动。

已核验固定 WinGet 包哈希、上游 tag/提交及动态登记源码，本机只读检查的 12 种常见格式全部满足 audio/video 登记条件。没有分类的扩展名属于上游边界；不增加产品补登记逻辑。详见 [证据](evidence.md#windows-软件包的媒体登记核验)。两端依赖材料仅同步版本及输入摘要，无新增依赖或许可原文变化。

本批已完成：Rust 默认 **60 通过 / 5 默认忽略**、严格静态检查、前端 **3/3**、离线预览和最终单 EXE 构建通过；最终程序侧栏专项 **1/1**、Windows 完整隔离原生套件 **8/8（269.83 秒）**通过，另含 **52 个真实 MPV 轨道子用例**。覆盖核心失败/取消/重试/升级/卸载、窗口、uosc、连播字幕、安装/配置手改保护、双语主题/默认应用入口、快捷键续播及草稿/过期计划/响应式布局。

最终 EXE 为 src-tauri/target/debug/mpvkit.exe，30,242,304 字节，SHA-256 **420bfaa61275be3814cd56987c5d7d5b21c6a10659a697a72788c716480b04bf**。完整回归使用此产物。前两轮新增测试的定位器/IPC 监测错误已修正，失败日志保留；详情见 [证据](evidence.md#windows-当前程序验证)及[机器摘要](windows-native-evidence.json)，不作产品故障或通过结论。

## 验证边界与下一任务

Windows 包登记采用用户允许的固定上游代码及已校验包内容核验，未执行主机安装器或修改默认应用。真实 UAC、干净系统 Shell 逐格式点击、物理鼠标、辅助技术、多屏/HDR/功耗等仍需专门环境；本地原生回归通过不代表这些项目已验收。

下一任务为 Linux Arch/CachyOS x86_64 / KDE Wayland 本版编译、默认套件与隔离原生实播，重点复验系统 MPV 直接启动、续播/播放期保存、卸载保留与独立管理器入口。本轮只维护 Linux 源码和测试调用，未编译或实机运行，不继承旧版通过结论。普通验证继续从新隔离根开始，不自动删除实际旧登记或配置。
