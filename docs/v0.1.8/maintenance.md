# 组件管理与自动清理（2026-10-26，已实施）

v0.1.9 更新：本文的文件维护策略继续适用；专属媒体登记及其卸载管理已删除，“设置默认应用”移到 MPV 核心行。相关当前决定以 [v0.1.9 交接](../v0.1.9/plan.md)为准，以下保留 v0.1.8 的实施记录。

用户授权删除历史备份、撤销、回退和手动缓存清理，不管理配置历史。此决定覆盖旧计划中保留历史副本的要求；当前事务的预览、过期检查、归属、安全写入和失败恢复保留。不迁移或清理此前开发版实际数据，测试使用新隔离根。

顶部统一组件管理：MPV 行未安装显示“安装”，已安装提供“检查更新”和卸载，确认存在更新后才显示“更新”，无更新显示“暂无更新”。增强按缺失、损坏、固定版本变化提供安装、修复或更新；健康且版本一致不显示重复操作，核心缺失不会触发健康增强重装。配置行安装后显示重置。明细归入此区域；路径、来源及系统打开方式保留低频选项。删除清理缓存、撤销、“允许备份并替换”入口。覆盖手改在具体操作的差异预览中确认，不保留永久授权勾选。

核心卸载通过固定包管理器：Windows WinGet shinchiro.mpv，Arch/CachyOS pacman，经 pkexec 正常授权，不绕过依赖检查、不递归卸载依赖。执行前说明影响其他调用核心的程序，执行后复核结果。核心卸载不额外清除配置，增强卸载不删除核心。

核心是否安装与能力健康分别检测，后端拒绝对已安装核心执行 install。主动检查更新：Windows 使用 WinGet 精确包的 --upgrade-available 列表；Linux 使用 pacman -Qu mpv，数据库错误不能当作无更新，不刷新数据库。Linux 安装/更新加 --needed，避免当前版本重复安装；增强按应用内内置组件清单比较，不查询上游最新发布。检查失败和状态刷新清除旧更新结果，确认弹窗分别显示安装、更新、修复。

重置恢复默认结构化播放器设置及 mpv.conf、input.conf、uosc/thumbfast 选项；先显示差异及无历史备份提示。普通 GUI 保存继续仅更新管理区。用户额外文件、续播、应用外观偏好保留。

增强卸载按归属和摘要删除未改动的预设、脚本、字体、许可、helper 和自身系统集成，手改文件列入保留清单。清理不再使用的归属记录及已空生成目录，不递归删除 MPV 根或用户目录。

下载/解压使用已有有界内存缓冲，无磁盘下载缓存。当前事务暂存及原内容副本仅用于失败恢复，成功或恢复后立即自动清理。已持久化完成标记而中断的清理在下次状态检测重试；执行中或未恢复事务不能清理。仅处理记录对应文件，未知或已改动的临时文件保留并报告。原生组件缓存按组件机制处理，不清除播放记录，无后台清理服务。

验证覆盖包管理器卸载失败/取消/虚假成功、完整重置、手改覆盖预览、卸载保留用户内容、成功/失败/中断自动清理及目录边界。Windows 只隔离模拟包管理器，不改真实核心/默认应用；Linux 已补原生隔离部署/重置/卸载/清理与 Wayland 实播，真实 pacman/polkit 仍未运行。最终证据及下一任务写回 plan/evidence；不自动提交、推送或构建安装包。


实施状态：功能已完成；当前验证和单 EXE 结果见 [evidence](evidence.md) 末尾。卸载还会在同一文件事务中清理已退出且有归属、内容符合生成格式的会话日志，活跃/手改日志及未知文件保留。owner.json 和 operation.lock 保留为安全互斥的最小记录；不能删掉正在持有的锁。WinGet/pacman 共享缓存由系统包管理器管理，MpvKit 不越权清理其全局目录。

依据：[WinGet uninstall](https://learn.microsoft.com/en-us/windows/package-manager/winget/uninstall)、[pacman](https://man.archlinux.org/man/pacman.8.en)、[pkexec](https://www.freedesktop.org/software/polkit/docs/latest/pkexec.1.html)。WinGet 卸载仅使用 uninstall 支持的协议参数；pacman 只 -R mpv，不加 -s/-n/-dd；pkexec 禁用内部文本代理，使用桌面原生授权。取消、失败或超时后检查系统状态，不对系统包伪造回滚或清理其共享缓存。
