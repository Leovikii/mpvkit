- 最新功能批：Linux 默认 Rust **52 通过 / 3 默认忽略**；fmt、clippy all-targets、前端检查、TypeScript/Vite、离线预览和单 ELF 构建通过。

- 真实用户级管理器入口已登记；直接执行与 gio 桌面启动进入管理界面。KWin app_id/desktopFileName 为 io.github.mpvkit，标题栏及任务栏品牌图标已目视确认。87 个实际配置/偏好/默认应用相关路径快照未变。用户随后确认修复并授权推送，已完成 7fa64a2。
- 已知测试波动：原生套件首轮在 uosc 暂停按钮的即时断言失败，新隔离根复验通过；另一次旧回归曾遇 IPC 就绪但 time-pos 尚未生成，现已增加属性就绪等待。未放宽产品保护或修改 uosc 来迎合测试。
- Windows 当前批：Rust **63 通过 / 6 默认忽略**，另运行私有 hive 专项通过；fmt、clippy all-targets -D warnings、前端 3 项、TypeScript/Vite、单 EXE 与 Windows 依赖材料检查通过。全新隔离根完整原生回归 **8/8，292.55 秒**，另含 **52 个真实 MPV 轨道子用例**；追加浅/深色品牌断言的侧栏专项通过。
- Windows 首轮 7/8，失败为列表回绕时 playlist-pos 已更新而媒体尚未就绪，下一条 seek 被 MPV 拒绝；补 time-pos 就绪等待后全套通过。Windows 契约测试补一行 check_update 类型引用，修复严格 clippy 的 dead_code；未改产品行为。真实管理器桌面已目视检查中英/明暗、固定紫色和标题栏图标，192 DPI、DWM backdrop=2；不等于完整辅助技术或多屏验收。
