# MpvKit 界面开发规范

依据核对：2026-10-28。用于后续前端工作；当前界面见 [开发基线](../current.md)与[alpha.4 交接](../v0.2.0-alpha.4/plan.md)；本版见 [alpha.4 实施与交接](../v0.2.0-alpha.4/plan.md)。v0.1.5 仅为历史设计依据。本规范约束当前产品与后续界面修改。

## 依据与适用范围

采用微软 Windows 应用设计指导中的 WinUI 3 / Fluent 原则，以 Mantine 实现。不是将 WebView 改成 XAML，也不承诺像素级复制原生控件。以下是官方指导的项目化摘要，具体尺寸决策在下一节明确区分。

| 官方来源 | 采用的原则 |
| --- | --- |
| [NavigationView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/navigationview) | 稳定的顶层导航、内容区与导航分离，窄窗减少导航占用。官方也支持顶部导航；恢复左栏是本项目用户选择，不称为微软强制要求。 |
| [App settings](https://learn.microsoft.com/en-us/windows/apps/design/app-settings/guidelines-for-app-settings) | 设置是完整页面；入口位于侧栏底部；相关项成组，说明在左、控件在右；内容限宽；偏好修改即时反馈。SettingsCard 来自 Windows Community Toolkit，不是 Mantine 或 WinUI 内置控件。 |
| [Content layout and spacing](https://learn.microsoft.com/en-us/windows/apps/design/basics/content-basics) | 用一致的留白表达分组；按钮间距 8 epx，表面内边距参考 16 epx；正文和分组标题建立层次。 |
| [Typography](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/typography) | 正文常规字重、标题半粗、默认左对齐；使用系统字体和清晰字号层级。 |
| [Geometry](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/geometry) | 常驻控件圆角 4 px、弹层 8 px；相接边不重复圆角。 |
| [Mica](https://learn.microsoft.com/en-us/windows/apps/design/style/mica) | 材质用于窗口基底；内容层在基底之上。按系统能力、透明效果、节能和高对比策略回退，不能让每张卡片各自模糊。 |
| [Dialog controls](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/dialogs-and-flyouts/dialogs) | 标题直接说明任务、内容简短、按钮用明确动词；执行按钮在左，安全关闭在右；局部错误就地展示。 |
| [Progress controls](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/progress-controls) | 已知工作总量时显示确定进度，未知时用不确定指示及状态文字；下载完成不代表安装完成，不能伪造百分比。 |

不采用 Windows 7 旧版 UX 指导或 UWP 手机白皮书覆盖上述当前 Windows 页面。Microsoft Learn 页面会更新，后续修改应复核原文。

## 项目尺寸与视觉基线

下列是 MpvKit 的 CSS 逻辑像素选择，不是微软硬性指标。浏览器缩放/DPI 下使用 rem 和响应式布局；不按设备物理像素猜窗口大小。

| 项目 | 基线 |
| --- | --- |
| 导航 | 常规宽 216；窗口小于 900 时收为 64 图标栏；最窄验收 640。图标栏保留可访问名称及悬停/聚焦提示。 |
| 内容 | 左对齐、最大宽 1040；正常内边距 24，窄窗 16；导航固定，内容区独立纵向滚动。 |
| 留白 | 4 / 8 / 12 / 16 / 24 / 32；同类控件用同一组值，不逐页猜间距。 |
| 字体 | Segoe UI Variable → Segoe UI → Microsoft YaHei UI → sans-serif；页标题 28/600、分组标题 14/600、正文 14/400、辅助信息 12/400。 |
| 控件 | 默认高度约 32，导航行 40，信息行最小 64；文字增长时允许增高，不裁切。触摸设备保持 Mantine 正常尺寸，不压缩命中区。 |
| 圆角 | 按钮/输入/分组 4，页面内容面/对话框 8。 |
| 表面 | 窗口基底、内容面、弹层三层。分组用轻边框；常驻内容无阴影，弹窗保留组件阴影；不用渐变横幅、玻璃卡片和大面积强调色。 |
| 颜色 | 中性色为主；强调色只用于主要动作、当前导航指示和焦点。状态必须有文本，不能只靠红绿。界面强调色固定为图标同源的 #A84BD6 紫色，使用一套 Mantine 色阶提供悬停与文字层次；不提供颜色选择或系统强调色跟随。图标继续复用现有 MPV SVG/PNG/ICO。 |

预览用纯色模拟窗口基底；浏览器无法验证真实 Mica。产品保留现有原生标题栏和自动材质逻辑，不增加第二套窗口控制或材质开关。

## 组件复用与页面结构

Mantine core/hooks 继续固定 9.7.3。按 [官方快照](../vendor/mantine/README.md) 阅读实际组件正文，并核对本地声明。优先用组件 props、主题及公开 Styles API；不依赖内部哈希类名，不手写焦点锁、下拉菜单、复选框或折叠动画。

| 用途 | 使用现有组件 |
| --- | --- |
| 窗口内布局、左栏及底部设置入口 | AppShell、AppShell.Section、NavLink；通过 button 语义、aria-current 标记当前位置，无需引入路由库 |
| 分组及设置行 | Paper + Group / Stack；只复用一种简单行布局，不做通用配置表单引擎 |
| 高级项、组件明细 | Accordion，设置正确 heading order；Control 内不嵌套按钮/输入 |
| 参数 | NativeSelect、TextInput、Checkbox；需确认的系统变更不能伪装成即时生效 Switch |
| 提示、进度 | Alert、Progress 或现有原生 progress；错误在相关区域，完成提示 aria-live=polite |
| 确认 | Modal；保留 trapFocus、returnFocus、Esc、可访问标题；执行中关闭规则沿用业务约束 |

当前采用两页：**播放器设置 / Player settings**（组件安装和状态、预编辑、配置预览与保存）、**应用设置 / App settings**（软件语言、外观、关于、诊断）。首次无组件仍可编辑；实际配置保存前检查必需组件。播放器设置底部固定操作栏，内容单独滚动。详见 [v0.1.6](../v0.1.6/plan.md)。

页面只设一个 h1。顶端标题配简短说明和至多一个次要全局动作；主要按钮放在对应任务附近。不要在每张卡片重复标题、状态和一组相同按钮。每个任务区域只有一个强调动作，正常状态用普通文字而非一排彩色徽章。

相关信息合并为行：名称与一行说明在左，状态/控件/操作在右。窄窗自动上下排；完整路径可折行；两个目录入口必须一致：左侧标题“打开安装目录 / 打开配置目录”、副标题为实际路径，右侧“打开”。正常页不直接展示 JSON、哈希、来源 URL 列表或完整配置。相关详情折叠，不能删除审计信息。

默认推荐足够使用。主配置区依次展示画质、HDR 输出、自动连播和全部播放结束后。自动连播使用有可访问名称的 Mantine Switch，默认开启，说明其作用为同文件夹音视频按文件名排序连播；结束行为使用下拉选择关闭播放器或保留窗口。顶部组件区统一显示核心安装/更新/卸载、增强安装/移除、组件明细和安装后的配置重置。高级选项默认关闭，包含目录入口与来源；“设置默认应用”普通按钮位于 MPV 核心操作行，不是配置开关，核心安装后可用。不展示无设置项的快捷键帮助，不提供管理器内打开媒体入口。危险操作必须有文字标题及确认；当前冲突、失败、恢复要求必须浮出高级区，不能藏在折叠内容里。

画质默认均衡，仅在首屏选择框旁显示对应档位的简短建议；不检测硬件，不展示显示器、分辨率、显卡、供电信息或自动推荐操作。具体文案与完整删除边界见 [播放默认值](../v0.1.5/playback-defaults.md)。

HDR 默认自动，与画质同组保留自动/强制 HDR/关闭 HDR（SDR）三态覆盖。音轨与字幕语种不提供 GUI 控件（包括高级区），默认汉语→日语→英语→西班牙语；语种标签依据与文件手改约束见 [播放默认值](../v0.1.5/playback-defaults.md)。

设置采用完整页，语言与外观、关于、高级诊断成组。主题和语言即时反馈；播放器配置需明确预览和保存。切页面保留草稿，不隐式保存或取消下载。

## 对话框与文案

2026-10-22 最终审阅：删除界面中不影响当前选择的说明，包括默认语种顺序、如何编辑 mpv.conf、默认行为罗列和重复推荐句。技术依据留在开发文档；保留“打开配置文件夹”按钮。页面不在菜单或选项之外堆放常驻说明段落（如“推荐配置即可开始播放”“默认记忆播放位置”“写入前会显示具体变更”）；需要的选项说明就近作为副标题。独立设计预览必须同步遵守此规则，不能遗留旧文案误导审阅。菜单与按钮优先使用短动词/名词，中文和英文同时精简。HDR 自动/关闭不附解释，只有强制开启时提示使用条件；画质建议仍就近显示。保留当前错误、冲突、覆盖授权、删除/重置后果和必要状态，不以精简为由隐去风险。

默认宽约 560，复杂文件差异最多 720，窄窗限制为视口减 32。内容可滚动，操作区始终可达；不叠加第二个确认弹窗。

短确认弹窗按实际标题/必要短正文/按钮自适应高度，不沿用长日志任务的空白占位。标题和正文保持同一表面，操作区可轻微分区，但不能在中间留下无内容色带。页面卡片的 Paper 背景须限定作用范围，避免影响 Modal；不叠加多套操作区 margin/padding。alpha.4 已修复退出确认的空白色带；共享样式调用方包括任务、更新及退出弹窗。

顺序：动作标题 → 简短影响摘要 → 固定目标 → 冲突/保留内容（如有）→ 可展开文件明细 → 执行、取消。主按钮叫“安装”“保存”“卸载”，不泛称“确定”。默认不展示原始 JSON；技术详情仍可展开。手改冲突及执行阻断不能被摘要隐藏，不能因视觉精简绕过预览、复核或当前操作失败恢复；不保留历史备份、撤销及手动组件缓存清理。

危险操作默认聚焦取消；普通操作保留安全可达的取消。不对默认安装目录弹出“修改目录”确认。媒体登记交给系统 MPV 包；默认应用快捷入口只打开系统设置，不得声称已设为默认播放器。

文案面向用户：说明对象、状态、下一步。优先“尚未安装”“生成配置”“配置已保存”“修复播放器”。不要“初始化部署流程”“目标环境健康性”等术语。每段原则上一至两句；语义需要时允许更长。中文和英文同等支持，禁止只缩短中文而让英文溢出。

## 动效规范（2026-10-22 补充）

依据微软 [Page transitions](https://learn.microsoft.com/en-us/windows/apps/develop/motion/page-transitions)：左侧导航切换顶层页面采用 Page refresh，即新内容向上进入并淡入；更深层详情才适合 Drill，横向同级导航才使用横向滑动。这里的 Page refresh 指视觉过渡，不是重新加载应用或执行刷新接口。参考 [Animations overview](https://learn.microsoft.com/en-us/windows/apps/develop/motion/xaml-animation)，优先保留标准控件内建动效，以状态反馈为目的，避免分散注意力。

| 场景 | Mantine 实现与项目选择 |
| --- | --- |
| 左侧导航切页 | 内置 Transition `fade-up`，进入 200 ms、ease-out；使用库自带 30 px 位移，不写自定义关键帧。旧页立即移除，只动画新页，不移动标题栏/侧栏。该参数是本项目选择，不是声称复刻 XAML 动画时间曲线。 |
| 页面承载 | Transition 官方主要面向 fixed/absolute 的呈现；在固定内容面内放置绝对定位、独立滚动的页面层。只保留一个页面，避免两个可交互页面重叠。 |
| 高级选项与组件详情 | Accordion 内建高度、淡入淡出及箭头旋转，180 ms；不另写高度测量或折叠动画。 |
| 确认弹窗 | Modal 的 transitionProps：内置 fade，进入 160 ms、退出 120 ms；保留焦点锁和返回焦点。 |
| 工具提示 | Tooltip 内建 fade，进入 120 ms、退出 90 ms；保留悬停及键盘触发。 |
| 按钮、选择框、复选框、导航 | 保留 Mantine 原有悬停/按下/选中反馈与可用的内建过渡；没有动画的原生控件不另造替身，不增加弹跳、波纹或逐项进场。 |
| 异常与进度 | 保持即时可见，不能等待动画才提示失败、允许取消或阻止危险操作。不让每次进度更新重播整个页面。 |

时长统一在 theme.defaultProps 或唯一页面过渡处管理；不加动画依赖、路由动画框架、通用动画状态机或全局 `transition: all`。不为实现退出动画延迟业务切换。切换过渡仅随 page key 发生，编辑参数、主题切换和状态刷新不重播页面；快速连续切换以最后选择为准，组件负责清理动画计时。

开启 `theme.respectReducedMotion=true`，尊重 `prefers-reduced-motion`；保留减少动态效果的 CSS 兜底，以同时覆盖 Accordion 箭头等 CSS 动效。系统偏好关闭动画时页面直接出现，不能残留透明、位移、隐藏焦点或等待定时器。产品实施还需在 WebView 中验证 Windows“动画效果”开关的映射。

验证增加：正常动效与 reduce 两种模式、快速切页、再次点击当前页不重播、切页不丢草稿/下载、关闭弹窗动画后的焦点归位，以及长内容滚动位置正确重置。预览只演示页面和现有组件动效，不新增产品动画开关。

## 必需验收清单

后续实施必须检查：两页键盘导航、收窄导航提示、焦点可见、弹窗焦点恢复/陷阱/Esc、200% 文本缩放、简中/英文长文、浅色/深色/高对比/减少动态效果；640×600、900×700、1200×800 布局无横向溢出，滚动不遮挡操作。

覆盖空安装、仅核心、完整安装、核心损坏、更新可用、下载中/失败、配置手改冲突、文件事务失败与恢复。底层预览和失败恢复仍按现有测试要求验证。真实 Mica、DPI 和辅助技术需要原生窗口检查，浏览器预览不可冒充这些验收。

2026-10-22 布局复核：选择框宽度使用 rem 随字号缩放，设置行空间不足时换行；200% 文字检查同时验证选中文本未截断。异步弹窗必须在禁用触发控件前保留回焦目标，关闭且操作结束后恢复；目标已移除时回到可用导航。Mantine 仍负责焦点锁、Esc 和动效，不新增焦点锁实现。

2026-10-26 维护简化：手改覆盖在具体预览显示差异及无历史备份提示，不保留永久“允许备份/替换”勾选。重置预览明确恢复全部默认设置、快捷键和脚本选项；核心卸载说明影响使用同一系统核心的程序并保留配置。详见[维护方案](../v0.1.8/maintenance.md)。

2026-10-28 alpha.3 已实现样式：按钮背景进度及短状态，无重复横条或段落；其事实保留在 alpha.3 交接。

2026-10-28 alpha.4 已实施决定（覆盖上述旧样式约束）：确认、进度和结果留在同一个 Modal，一次操作只做一次应用确认。已知总量用独立 Mantine Progress，未知总量/校验/授权/安装用 Loader 与一行短状态；按钮不承载进度、不使用背景百分比，保留标准内边距和随文字增长的宽度，不刻意压窄或截字。操作区固定，主要动作在左，取消/关闭在右，窄窗可换行。下载完成不等于安装完成；系统授权另由 UAC/Polkit 处理，不叠加第二个应用确认。继续保留安装/重启影响、草稿阻断、手改差异和具体失败原因；完整准备/确认流程及双端边界见 [alpha.4 计划](../v0.2.0-alpha.4/plan.md)。
