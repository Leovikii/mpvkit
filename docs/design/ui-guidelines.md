# MpvKit 界面开发规范

更新：2026-11-05。当前实现为 [rc.1](../current.md)，本轮已授权实施与测试；验证及未测边界见[证据](../v0.2.0-rc.1/evidence.md)，公开版本仍为 beta.3。本文集中保留有效设计规则；历史方案与审查见 [beta.2](../v0.2.0-beta.2/plan.md#管理器组件审查)、[beta.3](../v0.2.0-beta.3/evidence.md#主界面增强明细与布局校正)。

## MPV 播放控件与 uosc

仅使用固定 uosc 的公开配置及菜单接口；上游 Lua 保持原文字节。禁止为布局/外观注入 Lua、包装内部方法、读取内部对象、修改源码、维护 fork 或自绘控件。自有画质/保存/窗口业务只经公开接口调用菜单，原生能力不足时简化需求。

当前左侧上一集/播放暂停/下一集，右侧播放列表/字幕/音轨/信息/更多/全屏；单音轨也显示，倍速只在菜单，底部为独立原生进度条。尺寸和默认外观见[当前基线](../current.md)。rc.1 已接入信息、按列表显示切集及统一激活菜单；具体顺序、原生条件边界和状态来源集中见 [rc.1 计划](../v0.2.0-rc.1/plan.md)，本页不复制一套目标参数。

菜单与提示在安装/完整重新应用时使用管理器解析后的单一语言；切换管理器语言不自动写配置。标签短而精确，不拼接双语、不写教程/技术参数；激活标记与键盘焦点区分，状态来源可靠才显示。风险留在必要确认或失败反馈中。

rc.1 实现中，画质/HDR/自动连播/播完后统一选中即应用并自动保存，移除画质独立保存与切集恢复；四项通过独立于 uosc 展示的共用保存模块更新默认配置，菜单不承担文件写入。保存失败须短提示，不能用运行期激活状态冒充已持久化；再次选择允许重试。管理器仍只提供画质控件，保存其他 GUI 设置不得重置菜单偏好；音量等未接入项不自动保存，具体职责与事务规则见[保存模块设计](../v0.2.0-rc.1/plan.md#播放默认值保存模块)。自有 Lua 按菜单业务与 Linux 窗口修复分成两份，不按设置项逐一拆分，见[拆分设计](../v0.2.0-rc.1/plan.md#lua-调查与已确认拆分2026-11-04)。

## 依据与适用范围

采用微软 Windows 应用设计指导中的 WinUI 3 / Fluent 原则，以 Mantine 实现。不是将 WebView 改成 XAML，也不承诺像素级复制原生控件。以下是官方指导的项目化摘要，具体尺寸决策在下一节明确区分。

| 官方来源 | 采用的原则 |
| --- | --- |
| [NavigationView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/navigationview) | 导航入口稳定，窄窗减少导航占用。beta.1 只保留默认配置页与设置入口，不使用 NavigationView 侧栏；这是项目取舍，不称为微软强制要求。 |
| [App settings](https://learn.microsoft.com/en-us/windows/apps/design/app-settings/guidelines-for-app-settings) | 设置是完整页面，相关项成组，说明在左、控件在右，内容限宽，偏好修改即时反馈。右上角设置与页内返回是本项目选择。SettingsCard 来自 Windows Community Toolkit，不是 Mantine 或 WinUI 内置控件。 |
| [Content layout and spacing](https://learn.microsoft.com/en-us/windows/apps/design/basics/content-basics) | 用一致的留白表达分组；按钮间距 8 epx，表面内边距参考 16 epx；正文和分组标题建立层次。 |
| [Typography](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/typography) | 正文常规字重、标题半粗、默认左对齐；使用系统字体和清晰字号层级。 |
| [Geometry](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/geometry) | 常驻控件圆角 4 px、弹层 8 px；相接边不重复圆角。 |
| [Mica](https://learn.microsoft.com/en-us/windows/apps/design/style/mica) | 材质用于窗口基底；内容层在基底之上。按系统能力、透明效果、节能和高对比策略回退，不能让每张卡片各自模糊。 |
| [Dialog controls](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/dialogs-and-flyouts/dialogs) | 标题直接说明任务、内容简短、按钮用明确动词；执行按钮在左，安全关闭在右；局部错误就地展示。 |
| [Progress controls](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/progress-controls) | 已知工作总量时显示确定进度，未知时用不确定指示及状态文字；下载完成不代表安装完成，不能伪造百分比。 |

不采用 Windows 7 旧版 UX 指导或 UWP 手机白皮书覆盖上述当前 Windows 页面。Microsoft Learn 页面会更新，后续修改应复核原文。

## 项目尺寸与视觉基线

下列是 MpvKit 的 CSS 逻辑像素选择，不是微软硬性指标。浏览器缩放/DPI 下使用 rem 和响应式布局；不按设备物理像素猜窗口大小。

| 项目 | 基线 |
| --- | --- |
| 窗口与导航 | 默认 560×760、最小 480×600，双端配置保持一致。无侧栏或图标导航栏；配置页右上角设置按钮，设置页左上角返回，均有可访问名称与键盘提示。 |
| 内容 | 左对齐；正常内边距 24，窄窗 16；两页铺满客户区，共用单一背景，无外围留白/描边/大圆角底板，独立纵向滚动；配置页底部主操作区固定，不遮挡末行。 |
| 留白 | 4 / 8 / 12 / 16 / 24 / 32；同类控件用同一组值，不逐页猜间距。 |
| 字体 | Segoe UI Variable → Segoe UI → Microsoft YaHei UI → sans-serif；页标题 28/600、分组标题 14/600、正文 14/400、辅助信息 12/400。 |
| 控件 | 选择/图标控件约 32，文字按钮使用 Mantine sm 的 36px 最小高度，信息行最小 64；文字增长时允许增高、换行，不裁切。设置和返回图标保留 Mantine 正常命中区及 Tooltip；不为窄窗压缩控件。 |
| 圆角 | 按钮/输入/分组 4，对话框 8；页面外围不加圆角。 |
| 表面 | 客户区使用统一窗口基底，不在其中另套有底色的整页容器；设置分组仅保留一层轻边框。底部操作区沿用页面背景；常驻内容无阴影，弹窗保留组件阴影；不用渐变横幅、玻璃卡片和大面积强调色。 |
| 颜色 | 中性色为主；强调色只用于主要动作、选中状态和焦点。状态必须有文本，不能只靠红绿。界面强调色固定为图标同源的 #A84BD6 紫色，使用一套 Mantine 色阶提供悬停与文字层次；不提供颜色选择或系统强调色跟随。图标继续复用现有 MPV SVG/PNG/ICO。 |

预览用纯色模拟窗口基底；浏览器无法验证真实 Mica。Windows 保留 DWM 标题栏与 Mica。Linux 使用 KWin 服务端窗口装饰（SSD），标题栏、按钮布局、边框和窗口阴影遵循用户 KDE 设置；不创建 GTK HeaderBar，不给系统装饰覆盖配色、高度或阴影。此决定覆盖 alpha.5 标题栏与内容区统一染色的旧要求。应用内浅深主题仅改变内容区，不能强制系统标题栏同步。

Linux 内容区仍通过标准 Wayland 背景效果能力决定模糊，高对比或无能力时回退为实色；WebView 单独透明，不清空 GTK 窗口基底。不增加材质开关。KDE 桌面入口、Icon 名称与 Wayland app_id 统一为 io.github.mpvkit，由 Arch 包安装。标题栏是否显示图标及图标位置由系统装饰决定；独立 ELF 未安装桌面资产时可能出现默认 Wayland 图标，不为预览向真实用户目录注册资产。

原生验收核对服务端装饰协商、用户主题的按钮/边框/阴影及内容区可读性，不再要求系统标题栏与内容区同色。默认与最小尺寸指内容区，外框随系统装饰变化。

## 组件复用与页面结构

Mantine core/hooks 固定 9.7.3。先读[官方索引及相关正文](../vendor/mantine/README.md)，再核对本地声明；只用公开 props、主题和 Styles API，不依赖内部类名，不手写菜单、焦点锁、滚动或折叠逻辑。前端约束见[前端规范](../v0.1.0/frontend.md)。

| 用途 | 组件与约束 |
| --- | --- |
| 页面与导航 | Group/Stack；设置/返回用 ActionIcon + Tooltip，一个 h1，无侧栏；装饰图标 aria-hidden，操作有可访问名称 |
| 分组与行 | Paper + Group/Stack；统一行布局，说明在左、控件在右，换行仍靠右；不建表单引擎 |
| 设置 | NativeSelect/TextInput/Checkbox，关联可见 label；即时偏好用 Switch，需确认的系统操作不用即时开关 |
| 高级与核心管理 | Accordion 有正确 heading order，Control 内不嵌按钮；核心操作用 Mantine Menu，保留危险项与键盘语义 |
| 反馈与弹窗 | Alert/Progress/Loader、Modal；保留可访问标题、trapFocus、returnFocus、Esc；错误就地显示，普通结果礼貌播报 |
| 滚动 | 页面 ScrollArea、弹窗 ScrollArea.Autosize；8px 轨道、type=auto、仅溢出时出现，高对比滑块用 ButtonText |

配置/设置两页保持 560×760、最小 480×600。配置页安装前可编辑画质，切页保留草稿；主播放设置仅画质，不在高级区复制 HDR/自动连播/结束行为。播放增强直接显示 uosc、thumbfast、字幕字体的名称、用途、已装版本及各自状态，不加逐组件操作；thumbfast 提交号显示七位，完整来源留高级。高级只放目录/来源/重新应用，冲突、失败和恢复不能藏在折叠内容中。

分组标题在卡片外，14px/600，标题下距 8px、组间 24px；行主文案 14px/400、辅助文案 12px/400，状态右对齐。信息行最小 64px、内边距 16px，分隔线低对比，首行前无额外横线。两页和底栏水平边距常规 24px、宽度不超过 520px 时 16px；这些是项目值，不是微软强制像素。

未安装为“一键安装”，已安装为“一键卸载”；有草稿时保存为主动作，卸载为次要危险操作；缺损统一修复。主页主动作最右，页内及设置页工具按钮成组靠右。每个任务区域只有一个强调动作，不重复摘要和徽章；目录可折行并有打开按钮，正常页面不展示 JSON/哈希/来源列表。画质建议就近简短展示，不检测硬件或推荐档位。

设置按语言/外观、MPV、应用更新分组；语言/主题/预览版偏好即时保存。MPV 保留版本、状态、来源和安装/管理入口，默认应用快捷入口仅打开系统设置。底部为“打开日志文件夹”和本地 GitHub 图标 + Leovikii 按钮，仓库按钮有明确可访问名称；无版权许可列表或诊断导出表单，许可仍随包分发。日志边界见[当前基线](../current.md)。

图标复用本地 SVG、currentColor 及显式尺寸；按钮用 leftSection/rightSection，不用字体字符或逐字位移。文字按钮保留 Mantine sm 最小高度，公开 root/inner/label 支持自动高度，inner/label 为 auto、行高 1.5、text-box-trim=none、允许换行。中英文字范围完整落在 label 内，离按钮四边至少 4px；不得用裁剪、缩字号或单独垫高某语言规避问题。

长路径/配置/日志/更新说明自动折行，随所在页面或弹窗整体滚动，不嵌套限高 pre；滚动区可键盘聚焦并有名称，底部操作固定、末行可达。Modal 最大高度沿用原生 yOffset 计算，不再叠加独立视口高度公式；content 只约束 flex/overflow，避免内外双滚动条。共享 Paper 背景限定范围，短确认弹窗按内容增高，不留无内容色带。

## 对话框与文案

预设提示在主设置上方：旧修订“预设已更新”，未完整应用“可重新应用配置”，操作“重新应用配置”。点击才展示目标、差异及“按当前设置覆盖配置手改，无备份。”；成功复核后消失，失败/取消保留，不自动弹窗、不增已读/忽略状态。非紧急提示用 role=status 和礼貌播报，真实错误用 alert；[双语文案](../v0.2.0-beta.2/plan.md#提示文案)继续适用。

任务按动作标题 → 必要摘要 → 目标 → 风险/冲突 → 可展开明细 → 操作排列。确认、下载、校验、安装、结果及重试留在同一 Modal，一次应用确认；配置安装先生成本地具体预览，确认后才下载。已知总量用独立 Progress，未知阶段用 Loader + 一行状态；按钮不承载进度、不伪造百分比。固定操作区主动作在左、取消/关闭在右，窄窗可换行；按钮用明确动词。

核心缺失先等待原生包管理器成功退出并复核，再部署配置；系统 UAC/Polkit 和包管理器交互保留，不代答、不以关终端或启动进程成功代替完成，不强杀包事务。下载完成不等于安装完成；失败说明具体阶段。

Windows 普通安装在 rc.1 已确认保留原生完成页，尚未实施：标题“安装完成”，默认勾选“启动 MpvKit”，按钮“完成”；英文对应 Installation complete、Launch MpvKit、Finish。点击完成后按勾选状态启动并关闭安装器，不另弹确认或倒计时。应用内更新继续自动重启，静默安装不显示完成页；详见 [rc.1 方案](../v0.2.0-rc.1/plan.md#windows-安装后启动)，不改变管理器内安装确认顺序。

完整卸载提示“将删除此 MPV 配置目录及全部内容，包括其他脚本、手改配置和续播记录。”，同时显示实际目录；“同时卸载 MPV”默认不选。核心失败/取消仍执行已确认的配置删除，分别报告、只重试失败阶段；设置内独立核心卸载保留配置。危险操作默认聚焦取消，不增加默认路径修改确认；真实错误、覆盖/删除后果及恢复要求不得因精简而隐藏。

正文与菜单短而直接，中英同步精简；删除教程、默认语种列表及重复推荐。必要说明就近展示，不堆常驻说明段落，不给已删除控件增加只读摘要。确认宽约 560、复杂差异最多 720、窄窗不超视口减 32；操作始终可达，不叠第二层确认。

## 动效规范（2026-10-22 补充）

依据微软 [Page transitions](https://learn.microsoft.com/en-us/windows/apps/develop/motion/page-transitions)，既有页面切换采用 Page refresh，即新内容向上进入并淡入；更深层详情才适合 Drill，横向同级导航才使用横向滑动。beta.1 按用户要求继续保留现有过渡，设置/返回不另加横向滑动。这里的 Page refresh 指视觉过渡，不是重新加载应用或执行刷新接口。参考 [Animations overview](https://learn.microsoft.com/en-us/windows/apps/develop/motion/xaml-animation)，优先保留标准控件内建动效，以状态反馈为目的，避免分散注意力。

| 场景 | Mantine 实现与项目选择 |
| --- | --- |
| 配置/设置切页 | 内置 Transition `fade-up`，进入 200 ms、ease-out；使用库自带 30 px 位移，不写自定义关键帧。旧页立即移除，只动画新页，不移动标题栏/窗口外壳。该参数是本项目选择，不是声称复刻 XAML 动画时间曲线。 |
| 页面承载 | Transition 官方主要面向 fixed/absolute 的呈现；在固定内容面内放置绝对定位、独立滚动的页面层。只保留一个页面，避免两个可交互页面重叠。 |
| 高级选项与来源 | Accordion 内建高度、淡入淡出及箭头旋转，180 ms；不另写高度测量或折叠动画。 |
| 确认弹窗 | Modal 的 transitionProps：内置 fade，进入 160 ms、退出 120 ms；保留焦点锁和返回焦点。 |
| 工具提示 | Tooltip 内建 fade，进入 120 ms、退出 90 ms；保留悬停及键盘触发。 |
| 按钮、选择框、复选框、菜单 | 保留 Mantine 原有悬停/按下/选中反馈与可用的内建过渡；没有动画的原生控件不另造替身，不增加弹跳、波纹或逐项进场。 |
| 异常与进度 | 保持即时可见，不能等待动画才提示失败、允许取消或阻止危险操作。不让每次进度更新重播整个页面。 |

时长统一在 theme.defaultProps 或唯一页面过渡处管理；不加动画依赖、路由动画框架、通用动画状态机或全局 `transition: all`。不为实现退出动画延迟业务切换。切换过渡仅随 page key 发生，编辑参数、主题切换和状态刷新不重播页面；快速连续切换以最后选择为准，组件负责清理动画计时。

开启 `theme.respectReducedMotion=true`，尊重 `prefers-reduced-motion`；保留减少动态效果的 CSS 兜底，以同时覆盖 Accordion 箭头等 CSS 动效。系统偏好关闭动画时页面直接出现，不能残留透明、位移、隐藏焦点或等待定时器。产品实施还需在 WebView 中验证 Windows“动画效果”开关的映射。

验证增加：正常动效与 reduce 两种模式、快速切页、再次点击当前页不重播、切页不丢草稿/下载、关闭弹窗动画后的焦点归位，以及长内容滚动位置正确重置。预览只演示页面和现有组件动效，不新增产品动画开关。

## 必需验收清单

- 设置/返回/菜单键盘、图标提示、焦点可见及恢复、Modal 焦点锁/Esc；200% 文本、中英文、明暗/高对比/减少动态效果；480×600、560×760、720×800 无横向溢出或按钮遮挡。选择框用 rem，选中文字不裁切；异步任务禁用触发器前保留回焦目标，目标消失时回到可用导航。
- 空安装/仅核心/完整安装/缺损、下载和更新失败、手改冲突、过期预览与事务恢复；核心失败不部署、配置失败保留已装核心；完整卸载的可选核心、部分失败及路径/锁保护。所有删除只在隔离根验证。
- 动效、正常/reduce、快速切页、草稿/下载保留、滚动位置和回焦按上节执行。真实材质、KDE 图标/装饰、DPI、辅助技术及双端更新重启须原生验收，浏览器预览不代替。

历史尺寸、三页、按钮背景进度、旧重置/备份和逐组件设计不再作为当前要求；原始决定与证据留在对应版本交接。rc.1 的菜单/控件/安装后启动验收以[当前计划](../v0.2.0-rc.1/plan.md#实施顺序与验收)为准，尚无本版运行结果。
