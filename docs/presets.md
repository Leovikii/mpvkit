# 预设配置设计

MpvKit 将 MPV 核心、播放增强和配置分开管理。核心由 Windows 的 WinGet 或 Arch 的 pacman 维护，保存配置不会重复安装核心；原来的系统 MPV 打开方式继续可用。

本页描述当前 [beta.3 版本](v0.2.0-beta.3/plan.md)：管理器仅保留默认画质选择；HDR、自动连播、结束行为分别默认自动、开启、退出，并提供 uosc 菜单操作。安装/重新应用生成管理器对应语言的单语言文本，菜单只用简洁精确的标签。切换管理器语言后通过完整重新应用更新播放器文本，下次启动生效；普通保存保留已安装的语言。

## 画质与 HDR

默认使用**均衡**预设和 **HDR Auto**，也可选择节能或高画质：

| 预设 | 主要设置与取舍 |
| --- | --- |
| 节能 | 双线性缩放，关闭较复杂的缩放处理；名称表达配置目标，不保证每台设备都更省电 |
| 均衡 | Lanczos 放大、Hermite 缩小，开启线性缩小与 Sigmoid 放大 |
| 高画质 | EWA Lanczos Sharp 放大，增加抗振铃与 HDR 峰值 / 对比恢复处理，可能增加 GPU 负担 |

HDR Auto 交由 MPV 处理；实际 HDR 输出取决于系统、显示器和驱动。MpvKit 不检测硬件后自动推荐画质，也不承诺预设一定改善所有片源。完整参数见[预设源文件](../resources/profiles.json)。

管理器可在安装前设置默认画质；三套 profiles 都会写入原生配置。右键菜单允许临时切换画质，切集恢复启动配置；“保存为默认”下次启动生效。HDR 菜单提供自动/开启/关闭，临时调整当前进程；不在管理器提供 HDR 控件。

## 播放默认行为

- 自动将同文件夹音视频按文件名自然排序加入队列，不扫描子目录；可以关闭自动连播。
- 自动连播菜单开关影响后续打开文件，不重建当前队列，与列表循环分开。全部队列结束后默认退出，可在菜单改为保留窗口。两项菜单操作只在当前进程生效，不写入全局默认。
- 自动搜索同目录及 `sub`、`subs`、`subtitle`、`subtitles` 中匹配的字幕，Linux 兼顾常见大小写。
- 记住播放位置，不恢复上次音量；音量快捷调节步长为 10，字幕默认使用文楷字体。
- 窗口按屏幕宽高的 75% 范围启动并保持视频比例，切集时保留当前窗口大小。
- uosc 提供播放控制、轨道、倍速与播放模式，dev 后续布局优先展示字幕与音轨（单音轨也显示），倍速收入更多菜单；thumbfast 提供进度条缩略图；图标描边与按钮背景使用上游默认。双击视频切换全屏，空格播放 / 暂停。

## 配置与手动修改

配置写入 MPV 原生目录，常规位置为 Windows 的 `%APPDATA%\mpv` 或 Linux 的 `~/.config/mpv`；已有原生路径设置会参与检测，存在路径歧义时停止写入。

保存前可以预览实际变更。普通保存保留可手改区域；覆盖冲突需要确认。预设以整套修订号判断更新，程序升级不会自动覆盖配置；页内提示后由用户选择“重新应用配置”，按当前页面选择恢复完整预设，覆盖预设文件手改，无历史备份或撤销。重新应用保留未知内容及续播；一键卸载经确认后删除已展示的整个配置根，可选同时卸载系统 MPV，具体边界见[当前基线](current.md)。
