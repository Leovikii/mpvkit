# 预设配置设计

MpvKit 将 MPV 核心、播放增强和配置分开管理。核心由 Windows 的 WinGet 或 Arch 的 pacman 维护，保存配置不会重复安装核心；原来的系统 MPV 打开方式继续可用。

## 画质与 HDR

默认使用**均衡**预设和 **HDR Auto**，也可选择节能或高画质：

| 预设 | 主要设置与取舍 |
| --- | --- |
| 节能 | 双线性缩放，关闭较复杂的缩放处理；名称表达配置目标，不保证每台设备都更省电 |
| 均衡 | Lanczos 放大、Hermite 缩小，开启线性缩小与 Sigmoid 放大 |
| 高画质 | EWA Lanczos Sharp 放大，增加抗振铃与 HDR 峰值 / 对比恢复处理，可能增加 GPU 负担 |

HDR Auto 交由 MPV 处理；实际 HDR 输出取决于系统、显示器和驱动。MpvKit 不检测硬件后自动推荐画质，也不承诺预设一定改善所有片源。完整参数见[预设源文件](../resources/profiles.json)。

## 播放默认行为

- 自动将同文件夹音视频按文件名自然排序加入队列，不扫描子目录；可以关闭自动连播。
- 自动搜索同目录及 `sub`、`subs`、`subtitle`、`subtitles` 中匹配的字幕，Linux 兼顾常见大小写。
- 记住播放位置，不恢复上次音量；音量快捷调节步长为 10，字幕默认使用文楷字体。
- 窗口按屏幕宽高的 75% 范围启动并保持视频比例，切集时保留当前窗口大小。
- uosc 提供播放控制、轨道、倍速与播放模式，thumbfast 提供进度条缩略图。双击视频切换全屏，空格播放 / 暂停。

## 配置与手动修改

配置写入 MPV 原生目录，常规位置为 Windows 的 `%APPDATA%\mpv` 或 Linux 的 `~/.config/mpv`；已有原生路径设置会参与检测，存在路径歧义时停止写入。

保存前可以预览实际变更。普通保存保留可手改区域；覆盖冲突需要确认。**重置会恢复完整默认预设，且没有历史备份或撤销功能。** 移除增强时仅清理归属明确且未改动的内容，保留手改文件、未知内容、续播记录与系统 MPV。
