## 产品定位

MpvKit 是 MPV 安装与配置管理器，面向希望获得可靠播放体验、又不想手工维护整套配置的桌面用户。

首版 Windows x64；正式支持的 Windows 版本和最低系统构建在 M0/M1 验证后公布。优先在 Windows 11 验证，Windows 10 的支持须有实际证据，不因 Tauri 能构建就默认承诺。

2026-10-21 版本顺序调整：紧接着的 v0.1.1 继续支持 Windows x64，优先完成 [UI 与首次引导重构](../v0.1.1/scope.md)；Linux 作为后续独立版本，版本号与日期另定。首版不承诺 ARM64、macOS、所有 Linux 发行版、Flatpak 或 Snap。

## 目标场景

| 场景 | 主要目标 | 配置方向 |
| --- | --- | --- |
| 4K 台式机播放 1080p 动画、真人 | 稳定、高画质放大 | 内置高画质链，可选经验证的增强 |
| 4K 台式机播放 4K SDR/HDR | 正确色彩与输出 | 不增加无必要的亮度超分 |
| 2560×1440 核显本播放 1080p | 画质与耗电平衡 | 内置均衡缩放、稳定硬解 |
| 核显本播放 4K 视频 | 有效下采样和低开销 | 内置下采样，控制额外处理 |
| 已有 MPV 用户 | 保留资产并获得管理能力 | 检测、预览、明确配置归属 |

屏幕分辨率、视频尺寸、实际输出画面尺寸是不同概念。窗口尺寸变化不能简单等同于换画质档位。检测结果是建议的依据，不是覆盖用户选择的指令。

## 必须交付的能力

| ID | 能力 | 用户可见结果 |
| --- | --- | --- |
| F01 | MPV 安装与检测 | 下载已验证 Windows x64 构建；识别常见本地位置或手动选择的现有 MPV，显示版本、路径、来源 |
| F02 | 设备与能力检测 | 显示可获取的 GPU、显示器、电源及 HDR 相关状态；未知信息明确标注，不伪造推断 |
| F03 | 配置推荐与微调 | 推荐省电、均衡或高画质；用户可以调整字幕、界面及已支持的播放选项，重新推荐不覆盖手动修改 |
| F04 | 基础组件 | 部署经过验证的 uosc 和 thumbfast，处理原有 OSC 冲突，验证缩略图辅助进程 |
| F05 | 变更预览与部署 | 展示下载、路径、覆盖文件和系统集成变更；支持进度、失败原因和安全取消 |
| F06 | 备份与恢复 | 替换前备份；可恢复上一成功版本；失败和异常中断不丢失原配置 |
| F07 | 文件关联 | 注册用户级“打开方式”；引导进入系统默认应用设置，由用户完成系统确认 |
| F08 | 播放中切换 | uosc 和快捷键使用同一入口切换受支持档位；本次使用或记为全局默认；管理界面关闭后仍可用 |
| F09 | 主动更新 | 用户触发检查并预览更新，使用已验证组件组合；保留上一成功版本及用户修改 |
| F10 | 卸载与清理 | 按安装记录移除自有组件和关联；保护外部播放器、用户修改文件、截图和备份 |
| F11 | 诊断 | 显示实际版本、配置来源、错误日志和检测限制；用户主动导出经处理的诊断信息 |

F09 首版可通过新版 MpvKit 随附的固定组件清单提供可用更新，页面比较“当前安装”和“本清单已验证版本”。不声称已检查互联网最新版本，也不要求建设远程组件目录服务。MpvKit 自身更新可使用发行页面下载安装包，自动自更新后置。

F08 仅承诺经验证可运行时切换的参数。需要重启的解码、后端或输出设置明确提示下次启动生效，不能显示为已即时应用。

## 安装与既有配置

默认创建用户级独立管理环境。可以使用已有播放器，但其二进制仍归外部所有，MpvKit 不负责删除或替换它。

首版支持两条清晰路径：

1. 独立部署：使用自有配置目录，并通过明确指定配置的启动入口播放。
2. 替换指定配置：用户在具体预览中选择替换，先备份受影响文件，检查现有脚本冲突。

不提供任意配置的智能合并。已有配置不受支持或冲突无法可靠解决时，保留原状并提供独立部署。检测到包管理器安装的 MPV 时按外部安装处理，不擅自调用包管理器升级或卸载。

## 画质和增强

基础档位为省电、均衡、高画质；增强为独立维度。默认关闭外部 shader，使用 MPV/libplacebo 的通用渲染能力。

高画质以目标版本的官方能力和 `high-quality` profile 为起点；均衡和省电参数必须通过验证。不能直接把官方 `fast` 当作完整笔记本方案，也不能把 `high-quality` 理解为每个处理阶段均取最高成本。

HDR 输出和映射独立于画质偏好；不默认开启强锐化、降噪、时域插值或动画专用处理。电池状态可影响推荐，不在用户不知情时反复切换其偏好。

外部着色器是条件性增量：若有一套方案在目标场景具有可见收益且通过兼容验证，可收录固定版本及开关；没有合格方案时可以发布不带外部 shader 的 v0.1.0。自定义 shader 导入与任意组合编辑不属于首发门槛。

## 页面范围

前端按用户要求使用Mantine组件库；遵守仓库保存的官方LLM文档及[前端规范](frontend.md)。控件迁移不改变下列功能范围和后端数据保护要求。

- 概览：安装状态、设备信息、当前方案、启动播放器。
- 播放设置：档位、可选增强、字幕、界面和推荐理由。
- 组件与更新：已安装版本、清单版本、来源、安装及更新操作。
- 维护：诊断、恢复、卸载。

首次使用提供短向导。默认展示常用项，高级附加配置单独入口。保持键盘操作、焦点反馈、错误可读性和高 DPI 可用性。

## 明确后置

- Linux 运行支持、包管理器自动安装、多发行版打包。
- libmpv 内嵌播放、媒体库、视频 AI 分类、自动内容识别。
- 按文件或文件夹记忆、大量 shader 组合、插件市场、弹幕组件。
- 全参数 GUI、可视化条件规则编辑器、GUI 实时画面预览。
- 常驻后台服务、远程遥测、后台自动更新、MpvKit 自动自更新。
- 自动系统 HDR 开关、自动改默认播放器、自动刷新率切换。

后置项只有在明确改变版本范围并同步任务与验证要求后，才进入首版开发。
