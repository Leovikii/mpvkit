# MpvKit v0.1.0 开发候选说明

日期：2026-10-20。状态：未发布，尚未完成全部验收。当前代码、构建与测试证据见[实施计划](plan.md)和[验收台账](acceptance.md)。本说明不承诺正式支持尚未验证的环境。

## 已实现

- 固定来源的MPV/uosc/thumbfast下载、哈希验证与安全解包；本地播放器发现与外部归属保护。
- 独立管理环境或明确指定的现有配置目录；变更预览、备份、更新、恢复、卸载及归属清理。
- 三档播放设置、设备检测、字段覆盖、user.conf优先级；uosc/快捷键切换，GUI关闭后全局保存与多实例保护。
- 用户级打开方式登记及稳定--open入口、诊断脱敏导出、有界日志；单一用户级NSIS包。

当前构建要求WebView2 Runtime。安装器缺少它时从Microsoft下载引导程序，需要联网；本机未验证缺失Runtime的干净系统路径。组件获取同样需要联网，每资产10分钟总时限、60秒停滞/取消等待上限，连接10秒。

## 使用边界与已知限制

- 固定清单页面比较已安装组合与此应用随附组合，不表示查询互联网最新版本；应用自身没有后台自动更新。
- 外部shader默认不收录；不提供任意mpv.conf智能合并、媒体库、按文件记忆或全参数GUI。
- 播放中仅切换已验证的缩放/映射参数，解码/输出、字幕和界面调整下次启动生效。user.conf最后加载，可以覆盖GUI生成项。
- 受管理文件手工改变会阻止覆盖或启动；自定义放入user.conf，或通过明确备份恢复。旧安装代际的播放器不能覆盖新代际全局偏好。
- 默认应用由用户在Windows设置确认；开发验证未改开发者HKCU/UserChoice，私有蜂巢不替代资源管理器验收。
- 部分写入失败保留原目标、尽力清理本次半成品；持续故障导致回滚失败时保留恢复记录，故障解除后恢复。不承诺真实掉电或硬盘损坏下绝不丢失数据。
- 安装包附带third-party应用依赖原文/清单、固定Rust标准库版权汇编和已匹配的WebView2 SDK材料，并附仓库原始LICENSE。
- 当前产物未签名；源码/完整第三方审阅和纹理字体映射仍有缺口（图标字体已精确映射Google Apache-2.0），项目授权已明确为GPL-3.0-or-later，随包附带PROJECT-LICENSE.md与原GPL正文。releaseReady=false，不能作为已具备发布资格的声明。

本地构建产物及摘要见[验证报告](evidence/2026-10-20-v010-functional.md)。没有自动提交、推送、创建发行版或运行安装器。
