日期：2026-10-20。本轮仅新增开发维护工具、来源记录和文档；未修改产品Rust/React/Lua、依赖锁、组件载荷或安装包。上一轮已用固定官方SDK与源码完成[离线重建](2026-10-20-uosc-rebuild.md)，二进制不同；本轮补充实际运行时表中的对应证据，不把元数据一致认定为二进制等价。

## 固定输入与工具边界

[只读比较工具](../../../scripts/compare-uosc-links.go)使用官方Go标准库 debug/pe、debug/gosym 读取PE及运行时表，不自写PE或函数表解析器。先核对 source-materials 中固定的上游exe身份、重建报告身份/源码清单摘要，以及两exe和selected-files.json各自的大小/SHA-256。仅接受Windows amd64 PE64，检查节的文件边界，固定Go1.20+ amd64表头必须唯一；未知来源路径、缺少选中源码或解析错误直接拒绝。此工具专用于已验证的固定输入，不是任意Go/PE安全扫描器。

编译使用上一轮已校验的便携Go1.23.1 SDK，局部缓存/临时目录和关闭模块获取的环境；不安装Go、不执行两个ziggy。新Go文件仅属于可选维护入口，不加入Rust crate、应用资源或产品依赖。所有输出在 .local/v010-tests/uosc-links-0x0y3w4k；初始只读研究在 uosc-pe-k7hprg50，未改上游和重建输入。

在仓库根目录、按[重建文档](2026-10-20-uosc-rebuild.md)设置本次隔离SDK/环境后，可复验：

~~~powershell
go test -v scripts/compare-uosc-links.go scripts/compare-uosc-links_test.go
go vet scripts/compare-uosc-links.go scripts/compare-uosc-links_test.go
go build -o <新隔离目录>/compare.exe scripts/compare-uosc-links.go
# 参数依次为固定上游exe、重建exe、重建报告、选中文件报告；输出JSON到stdout。
& <新隔离目录>/compare.exe <ziggy-windows.exe> <ziggy-rebuilt.exe> <重建目录>/report.json <重建目录>/selected-files.json
~~~
