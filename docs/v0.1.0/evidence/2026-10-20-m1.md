## 可重复自动化入口及结果

在仓库根目录运行，首次依赖下载需联网：

~~~powershell
pnpm install --frozen-lockfile
pnpm build
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml --locked --all-targets -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml --locked
pnpm tauri build --debug --no-bundle
pnpm tauri info
~~~

前端类型检查及生产构建成功；Rust check 与严格 clippy 成功；11 项测试全部通过（0 失败，0 忽略）；Tauri 调试可执行文件构建成功，产物为 src-tauri/target/debug/mpvkit.exe。已生成 pnpm-lock.yaml、src-tauri/Cargo.lock；依赖安装未执行一键远程安装脚本。

11 项测试位于 src-tauri/src/launch/tests.rs；测试时使用 rustc 编译 tests/fixtures/mpv.rs 为专用模拟 mpv.exe，全部路径位于新建临时目录，结束后删除；不会访问真实播放器、用户配置或注册表。

| 风险 | 实际结果 |
| --- | --- |
| 预览意外写入 | 预览后管理根目录不存在 |
| 中文、空格、&、$ 变成 shell 语义 | 子进程收到完整单一媒体 argv；-- 分隔选项 |
| 预览后媒体或程序改变 | 执行拒绝，未创建管理目录 |

| 计划目录碰撞 | 拒绝复用，用户标记文件不变 |
| 确认后启动与归属 | 收到进程号；记录 schemaVersion=1、owner=MpvKit；参数及 started 日志正确 |
| 缺少必要参数 | 返回 unsupported_mpv |
| 查询卡住 | 100ms 测试期限内进入终止路径，总耗时小于 2 秒 |
| 输出超量 / 非零退出 | 返回 probe_failed，不把错误输出当版本 |
| UNC、设备路径、相对路径、父目录、备用数据流 | 本地路径校验拒绝；不访问远程路径 |
