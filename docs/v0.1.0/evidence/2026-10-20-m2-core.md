## 部署核心

新增 deploy.rs 与测试，使用 sha2 0.10.9（锁文件中已有版本）进行 SHA-256，使用 Rust 标准文件锁做跨进程互斥。Windows 单文件替换集中使用 MoveFileExW 的 replace/write-through；它不替代多文件恢复。

持久化格式全部 schemaVersion=1：

- .mpvkit/owner.json：内部目录所有权。
- install.json：受管理文件摘要、原件备份引用与摘要、外部 MPV、组件版本。
- pending.json：变更前后摘要、原安装记录、新安装记录、上一成功记录摘要；先落盘，再暂存/备份和修改目标。
- previous.json：上一成功操作及回退信息；失败恢复也恢复此前的 previous.json。
- backups/<操作 ID>/<文件序号> 与 staging/<操作 ID>/<文件序号>：本次明确创建的文件。原件备份与用户未知文件不自动删除。

预览只读、5 分钟有效；执行前和每个文件替换前重新核对状态。未知文件需要明确替换选项；已管理但有手工修改的文件阻止执行。外部 MPV 不能转成待覆盖的管理文件。卸载只恢复原件或移除仍匹配摘要的自有文件，保护未知文件与外部播放器。中断恢复检查当前状态只能是记录的前态或后态，新的用户修改使恢复停止并保留日志/备份。

13 项部署风险测试通过：预览只读、重复安装、原件恢复、过期与文件/记录变化、手工修改保护、损坏备份、文件占用后的多文件回滚、提交记录后中断、恢复中用户修改、真实子进程互斥、未知 schema/owner、路径/大小写边界和实际 junction 拒绝。
