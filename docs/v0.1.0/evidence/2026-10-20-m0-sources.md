## 完整包内容与集成影响

MPV 7z 使用本机 Windows tar -tf 列出，未提取执行：包含 mpv.exe、mpv.com、d3dcompiler_43.dll、mpv/fonts.conf、doc/manual.pdf、图标及一组安装/卸载/更新脚本。未见许可证、版权清单或依赖源码材料。后续仅取明确部署文件，保留必要构建许可材料；不调用其中 updater.ps1、bat 或注册脚本。7z 需要维护中的安全解包实现；M2 选型与路径/规模/链接限制测试尚未完成。

uosc.zip 使用 .NET ZipArchive 只读列条目。包内包括：

- fonts/uosc_icons.otf（400,360 字节）和 fonts/uosc_textures.ttf（38,228 字节）。
- scripts/uosc 完整 Lua、翻译与字符转换资源。
- scripts/uosc/bin/ziggy-windows.exe（6,017,536 字节），另有 Linux/macOS 的 ziggy。

因此不能只复制 Lua。uosc.conf 是单独发布资产，不在该 zip 内；该 zip 也没有 LICENSE.LGPL。Windows 首版不部署其它平台辅助二进制；ziggy 的源码位于固定提交的 src/ziggy，Go 依赖记录在根目录 go.mod。字体来源、辅助程序及 Go 依赖的分发材料仍须核实，不假设顶层 LGPL 自动覆盖全部第三方内容。

thumbfast 固定树只有 README.md、LICENSE、thumbfast.conf、thumbfast.lua，没有附带 Windows 可执行程序。该提交的 README 说明 thumbfast 会启动独立 MPV 产生缩略图，源代码默认 mpv_path=mpv；MpvKit 应显式指定选定播放器路径并验证隔离目录/辅助进程。使用 uosc 时不引入 thumbfast 为原生 OSC 提供的独立 osc.lua 变体。

## 许可证与能力依据

- uosc 固定提交的 [LICENSE.LGPL](https://github.com/tomasklaen/uosc/blob/d124c2c930d69446448022851373e00ae592390d/LICENSE.LGPL) 为 GNU LGPL v2.1 文本；项目许可适用及 only/or-later、字体和 Go 依赖义务仍须逐项确认。固定 [README](https://github.com/tomasklaen/uosc/blob/d124c2c930d69446448022851373e00ae592390d/README.md) 声明要求 mpv 0.33 及以上，这只是上游要求，不是本组合实测结论。
- thumbfast 固定 [LICENSE](https://github.com/po5/thumbfast/blob/0f711de3138c9bd6718209d819ac54022c23ded2/LICENSE) 为 MPL 2.0。README 表示尽力支持 Windows mpv 0.29 起，部分能力需要更新版本；不能据此承诺组合对旧版 MPV 的支持。
- MPV 源码/构建依赖的最终适用许可证、构建选项与完整分发材料未核实；不得只拿构建脚本仓库或 MpvKit 的许可证替代。
- MpvKit 自身 O09 精确许可证标识仍未决；LICENSE 未修改，未添加 only/or-later 元数据。
