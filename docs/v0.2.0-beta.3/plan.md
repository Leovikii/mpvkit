## 已确认范围

管理器继续负责安装、默认画质选择、维护和应用偏好；播放期控制集中到 uosc 菜单。保留两页、现有安装确认顺序、手改保护和事务，不建设独立远程预设发布或旧版兼容层。

| 项目 | 管理器及生成配置 | uosc 菜单 |
| --- | --- | --- |
| 画质 | 保留唯一的主播放设置选择框；安装前可选择默认档位，初始均衡；仍部署节能、均衡、高画质三套原生 profiles | 保留三档切换与“保存当前档位为全局默认” |
| HDR | 删除 GUI 控件，默认 Auto | 提供自动、强制 HDR、关闭 HDR（SDR）三项 |
| 自动连播 | 删除 GUI 控件，默认开启 | 提供开启、关闭；与随机、列表循环、单集循环分开 |
| 全部播放结束后 | 删除 GUI 控件，默认关闭播放器 | 提供关闭播放器、保留窗口两项；不增加立即退出动作来代替结束行为 |
| 播放器界面语言 | 安装及完整重新应用时使用管理器当前实际显示语言生成文本 | 每次只显示中文或英文，不拼接双语 |

“只保留画质”指主播放配置项；组件状态、高级目录/来源、预设提示、安装/保存/重新应用/修复/卸载，以及设置页语言、主题、核心管理、应用更新等现有入口继续保留。HDR、自动连播和结束行为不移入高级 GUI，也不新增只读默认值摘要。

## 菜单文案

用户明确要求菜单文本简洁精确，不得冗长废话。每次只显示对应语言的一列；菜单标题和选项不附教程、作用范围或实现说明。以下为目标文案，覆盖上表用于解释需求的长名称；现有其他菜单项同样去掉双语拼接并保持短标签。

| 项目 | 简体中文 | English |
| --- | --- | --- |
| 画质菜单 | 画质 | Quality |
| 画质档位 | 节能 / 均衡 / 高画质 | Power saving / Balanced / High quality |
| 保存画质 | 保存为默认 | Save as default |
| HDR 菜单 | HDR | HDR |
| HDR 选项 | 自动 / 开启 / 关闭 | Auto / On / Off |
| 自动连播菜单 | 自动连播 | Autoplay |
| 自动连播选项 | 开启 / 关闭 | On / Off |
| 结束行为菜单 | 播放结束后 | When playback ends |
| 结束行为选项 | 退出 / 保留窗口 | Exit / Keep window open |

“播放结束后”的“退出”仅设置结束行为，不立即退出；HDR 的“开启”对应现有强制 HDR 模式，“关闭”对应 SDR。风险或条件提示仅在确有必要时出现，保持短句；不得把开发文档中的技术解释直接写入菜单。

## 默认值与播放期行为

- 新安装和完整重新应用按当前页面的画质选择生成默认档位；若用户在播放器中已保存默认画质，管理器读取现有设置，不能无条件改回均衡。普通保存只改变用户选择的默认画质及必要记录，不重装健康组件。
- HDR 默认沿用两端现有 Auto 参数；自动连播为 `autocreate-playlist=filter`，保留 `directory-filter-types=video,audio` 与 `directory-mode=ignore`；全部队列结束后关闭播放器为 `keep-open=no`。不改变同目录自然排序、不扫子目录及显式播放列表的边界。
- 三项新增菜单操作以 MPV 原生选项/命令为基础，通过 uosc 公开菜单接口展示；HDR 各模式须完整设置关联参数，避免从强制模式切回 Auto 后遗留部分值。两端 SDR 参数保持平台职责，不能把 Windows 的处理直接复制到 Linux。
- 自动连播开关控制后续打开文件时是否自动建立同目录队列，不等于列表循环，也不通过清空或重建当前队列实现。目标 MPV 对运行期选项修改及后续打开路径的支持须实测；不能只根据菜单出现或属性写入成功宣称功能通过。
- 结束行为决定整个队列结束后退出或保留窗口，不表示每个文件结束都退出；与单集循环、列表循环的关系按 MPV 原生行为验证。
- 新增三项菜单选择只调整当前 MPV 进程，不增加自动写盘、全局保存按钮或管理器草稿同步。重启播放器读取配置默认值；需要永久手改仍使用原生配置。画质保留现有“当前文件临时切换、切集恢复启动配置、显式保存后下次启动生效”的范围，不顺带改成新的持久化模型。
- 普通保存继续保护可手改默认区；完整重新应用恢复 HDR Auto、自动连播开、结束后退出，并展示覆盖差异和风险。移除这三项的 GUI 草稿/设置来源，不为旧字段建设迁移或推断层；结构化设置仅保留实际需要管理的内容。

## 安装管理器对应语言的文本

1. 复用管理器现有的语言解析结果：明确选择简体中文/English 时使用对应语言；选择跟随系统时，使用管理器本次实际解析并显示的中文或英文。后端负责生成配置文本，前端不承担文件合并。
2. 单套菜单结构配中英文文案，生成 `input.conf` 自定义右键菜单标题、`uosc.conf` 自定义控件提示，以及自有画质菜单、OSD 成功/失败提示。不复制两套功能实现，不遗漏“当前”“仅本次”“保存为默认”等文本。
3. uosc 内置界面通过公开 `languages` 配置与之统一：中文使用 `zh-hans,en`，英文使用 `en`。不再依赖默认 `slang,en` 选择界面语言，也不改变 `alang/slang` 音轨/字幕偏好。固定上游 Lua、字体及翻译资源保持原文。
4. 切换管理器语言只即时改变管理器界面；已有播放器配置不自动改写。用户通过现有“重新应用配置”的具体预览与一次确认覆盖配置，下次启动 MPV 使用新语言。不新增播放器语言控件、同步按钮、额外提醒、后台检测或播放期语言 Lua，也不承诺已打开的 MPV 热切换语言。
5. 普通画质保存及播放期保存 helper 不顺带刷新已安装的菜单语言；完整重新应用才统一覆盖相关预设文本。继续复用手改保护、过期计划检查、锁、归属和失败恢复，不能为语言切换绕过文件事务。

### 固定上游能力依据

核对固定 uosc 5.13.0 对应提交的 [配置语言说明](https://github.com/tomasklaen/uosc/blob/d124c2c930d69446448022851373e00ae592390d/src/uosc.conf)、[国际化实现](https://github.com/tomasklaen/uosc/blob/d124c2c930d69446448022851373e00ae592390d/src/uosc/lib/intl.lua)与[菜单解析](https://github.com/tomasklaen/uosc/blob/d124c2c930d69446448022851373e00ae592390d/src/uosc/lib/menus.lua)：`languages` 支持语言优先级，`slang` 继承字幕语言；自定义 `#menu:` 标题按原文解析，不自动翻译。因此由管理器生成单语言文本，uosc 负责原生展示，不修改上游源码或读取其内部状态实现产品功能。
