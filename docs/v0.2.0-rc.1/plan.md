## 已确认范围与实现

| 需求 | 实现约束 |
| --- | --- |
| 统一选择 | 画质、HDR、自动连播、播完后选中即应用并保存默认；无“保存为默认”或切集恢复旧画质 |
| 菜单状态 | 画质/HDR/倍速/自动连播/结束行为/两种循环使用原生 active；读取实际属性，外部修改只刷新不保存 |
| 菜单顺序 | 常用设置置顶，不额外套“播放设置”；媒体操作居中，诊断与目录靠下 |
| 右侧 | 播放列表 → 字幕 → 音轨 → 信息 → 更多 → 全屏；信息调用 stats/display-stats-toggle |
| 左侧 | 上一集 → 播放/暂停 → 下一集；列表 0/1 项隐藏两侧，至少 2 项同时显示；首尾仍保留两侧 |
| 完成页 | 普通双击成功后等待用户点击完成，默认勾选启动；取消勾选不启动；不增加其他向导 |

保持两页管理器、安装前画质编辑、首次 HDR Auto/连播开/队列结束退出。管理器仍只显示画质，普通保存/修复/完整重新应用保留其余三项。语言只在安装/完整重新应用时选择，普通保存沿用安装语言；不改变 alang/slang。

### 播放默认值保存模块

- Rust `preferences::Update` 只接受 `profile`（power-saving/balanced/high-quality）、`hdr`（auto/on/off）、`autoplay`（JSON boolean）和 `when-finished`（quit/keep-open）。拒绝未知项目、非法值与附加字段，不接受任意属性/命令/路径/配置文本。
- `--save-playback <root> <JSON update> <expected revision> <generation>` 只适配参数与结果；固定根、代际、修订、归属、摘要、稳定锁及失败恢复继续由原有模块执行。读取设置前记录状态/清单摘要，并挂入计划守卫，避免读取到计划形成之间的竞争覆盖；返回本次事务对应的新代际/修订，后续已变化则报过期。
- 每次只改一项，保留最新通过检查的其他设置；四项默认值写入既有管理区，profiles 保持三档和平台 HDR 完整参数。无关可手改默认区和未知内容保留。普通保存不抬升预设修订；首次完整应用/重新应用成功才记录修订 4。
- 管理器预览/保存/修复/重新应用从磁盘读取最新 HDR、连播和结束行为，画质仍使用当前页面选择；长期开着的旧 GUI 草稿不能覆盖播放器后来保存的三项。读取前后继续核对既有指纹及事务守卫，预览后改变则报过期。
- Lua 顺序执行保存请求，不因正在保存而丢弃连续选择。只有 helper 事务成功才推进预期代际/修订；跨实例或管理器修改仍报冲突，不热同步其他已运行播放器，不无限重试。
- 同值且文件无差异时不写盘；保存失败后再次选择已激活项允许重试。运行期成功、保存失败时保持当前值并提示“保存失败，下次启动不保留 / Save failed; change will not persist”。原生应用失败恢复本次修改，不提交保存。
- 观察属性、打开菜单、音量/静音/倍速/随机/循环/轨道/设备选择不写默认值；播放位置仍由 MPV 原生按文件续播。

没有新增另一套写入系统、旧版迁移或任意 mpv.conf 合并器。缺少新增偏好字段时按首次默认解码，不从旧文件或当前进程反推偏好；旧预设需用户主动重新应用，不自动重写。

### 菜单状态与文案

| 菜单 | 中文 | English |
| --- | --- | --- |
| 画质 / Quality | 节能 / 均衡 / 高画质 | Power saving / Balanced / High quality |
| HDR | 自动 / 开启 / 关闭 | Auto / On / Off |
| 倍速 / Speed | 0.5× / 0.75× / 1× / 1.25× / 1.5× / 2× | 同左 |
| 自动连播 / Autoplay | 开启 / 关闭 | On / Off |
| 播完后 / When finished | 退出 / 保留窗口 | Quit / Keep open |
| 列表循环 / Playlist loop | 开启 / 关闭 | On / Off |
| 单集循环 / File loop | 开启 / 关闭 | On / Off |

只显示一种安装语言，激活样式由 uosc 渲染，不拼勾号/“当前”或教程。每次打开重新读取实际属性；打开期间属性观察合并到下一事件循环，通过公开 update-menu 刷新，无定时轮询。稳定子菜单 ID 保留层级、焦点、滚动和搜索。

- 画质/HDR 核对完整 profile 关联属性，不记最后点击值冒充状态；自定义组合不匹配时无激活。MPV 浮点选项有单精度回读差异，profile 数值用相对 `1e-6` 容差；倍速按六档数值精确匹配，不就近归档。HDR 标记只证明模式，不证明显示器 HDR 输出。
- 自动连播 `no` 关闭，其余原生模式开启；选择开启写回 `filter`，只影响后续打开，不重建当前队列。
- `keep-open=no` 退出，yes/always 保留窗口；选择保留写 yes，仅在整个队列结束生效，不立即退出。
- 有限/无限循环均激活开启，选择开启写 inf；两类循环独立，不改成互斥模式。
- 随机保留 uosc/shuffle 及其 OSD；固定版没有本批确认的公开状态 getter，不读内部对象或记点击次数伪造激活，也不改成打乱列表。

菜单只有一棵数据树，input.conf 只保留按键和右键消息，不复制完整菜单或解析任意 input.conf。原生轨道菜单继续调用上游公开 binding，保留其筛选和激活逻辑。

## Lua 调查与已确认拆分（2026-11-04）

调查时自有模板只有 161 行 mpvkit.lua，混合画质/保存与 Linux 首次窗口修复。rc.1 现已按两块职责拆分，不逐项拆脚本：

- `scripts/mpvkit.lua`：原消息目标，菜单数据/实际状态观察、受控原生应用、共用 helper 队列与失败反馈。删除临时画质快照、file-loaded 恢复和无消费者 `user-data/mpvkit` 缓存；测试改读真实属性/保存结果。
- `scripts/mpvkit-window.lua`：仅 Linux，独立读取 MPV 窗口属性，无偏好/helper/语言依赖；保留首个视频唯一落屏、0.5 秒安静期、复核后仅重设一次 autofit。显式 geometry/window-scale、全屏/最大化/最小化、尺寸变化、跨屏、切集仍取消；音频先行仍等待首个视频。没有更改时序。

两份脚本进入同一生成/预览/归属/摘要/修复/重新应用/卸载事务。健康检查包含运行脚本，缺失可修复，未归属同名脚本阻断覆盖；已修改受管脚本继续受保护。Windows 不部署窗口脚本。window-policy.lua 直接加载独立模板；仅在 Windows 运行其确定性策略不等于 Linux 合成器通过。

uosc 5.13.0 / `d124c2c930d69446448022851373e00ae592390d` 未升级，部署字节仍与固定上游一致；thumbfast、信息、轨道、队列及导航继续由上游/MPV 提供，不迁入自有实现。固定来源、许可证和未关闭审阅记录继续保留。

## 播放控件

统一尺寸 44、margin 12、spacing 6、原生进度条独占底行，上游描边/背景不改。信息按钮无媒体条件，点击切换原生 stats；不默认展开信息或强制常显整条控件栏。极窄窗服从原生收缩，更多菜单保留功能，不缩小命中区或加布局 Lua。

`has_playlist` 只判列表是否至少两项，不比较首尾位置。因此多项列表在首/末项也保留两侧按钮，运行期增删跟随更新；不承诺逐方向隐藏，不增加内部 bridge 或自绘溢出栏。

## Windows 安装后启动

保留 `$PassiveMode=1` 的直接安装与固定用户级位置，增加独立完成页条件，不恢复欢迎/许可确认/目录/开始菜单向导：

- 普通双击成功显示“安装完成 / Installation complete”，只有默认勾选“启动 MpvKit / Launch MpvKit”与完成按钮。完成前不启动，完成时按选择用现有 RunAsUser 启动一次；检查插件返回值，失败明确反馈。
- `/UPDATE` 或显式 `/P` 跳过完成页；官方 updater `/UPDATE /P /R` 继续既有自动重启及 `/ARGS`，不叠加完成页启动。
- `/S` 不显示完成页、不因本需求自行启动；显式 `/R` 保持上游语义。失败/取消不启动，卸载不启动，不增登录自启或修改默认播放器。
- Arch 安装仍只遵循 pacman 包管理语义，应用内更新保持现有重启；不在包脚本启动桌面程序。

模板沿用 Tauri CLI 2.12.3，来源/差异见[安装器说明](../../packaging/windows/README.md)。本机安全页面探针不写注册表、安装目录或真实配置，不能代替正式安装/真实更新验收。
