# MpvKit v0.2.0-rc.1

- Save quality, HDR, autoplay and end behavior directly from the player menu. Keep these choices when saving or reapplying configuration.
- Show active choices from actual player properties, with common playback settings at the top.
- Add an information button and show previous/next controls for playlists with at least two items.
- Finish ordinary Windows installation with an optional, checked-by-default launch. In-app updates keep automatic restart; silent installation stays silent.

Windows x64 and Arch/CachyOS x86_64. Verification and remaining device/system checks are recorded in the rc.1 plan and evidence.
