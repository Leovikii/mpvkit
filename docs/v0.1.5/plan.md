# v0.1.5 实施与交接

2026-10-22。用户已批准整体实施和必要本地测试，并要求删除无用说明、精简菜单文案。当前实施 v0.1.5；不升级依赖、不构建安装包；用户随后授权验证通过后提交并推送本批更新。

## 目标

恢复左侧导航，以统一的信息行、分组、留白和确认对话框建立桌面应用层次。执行 [界面开发规范](../design/ui-guidelines.md)，继续使用 Mantine，尽可能只调整布局、主题和文案，不重造原生控件。

## 页面方案

2026-10-22 审阅调整：对外名称采用“播放器 / Player”“播放设置 / Playback”“应用设置 / App settings”。下文“管理/配置”仅描述职责，不继续作为导航标题。副标题分别解释安装/更新/状态、画质/HDR 等播放偏好、软件语言/外观；最终界面省略重复副标题。首次配置按钮仍明确叫“安装配置”，不把文件写入伪装成即时设置。

页面切换新增微软左侧导航 Page refresh 语义：Mantine `Transition fade-up`，200 ms；折叠区 180 ms、弹窗 160/120 ms、提示 120/90 ms。其余控件保留库内建反馈，系统减少动态效果时直接显示。全部参数与验证要求见[动效规范](../design/ui-guidelines.md#动效规范2026-10-22-补充)。不新增动画库，不改变业务状态/IPC。

1. **窗口框架**：左侧“播放器”“播放设置”，应用设置固定底部；顶部保留轻量应用标识。无核心隐藏配置入口。导航只切页面，保留草稿/下载。常规侧栏 216，窄窗 64 图标栏，提示同时支持鼠标和键盘。
2. **播放器**：页面标题旁只有刷新；“播放器”分组显示 MPV 版本、安装/更新动作，播放增强作为可展开的同组行；“配置与系统”分组显示配置是否安装、真实修改时间及系统打开方式状态。路径和打开按钮同一行，收入高级选项；不提供管理器内打开媒体入口。修复、系统集成取消、备份恢复、清理、来源与卸载收入高级选项；异常必须就地显露并提供恢复动作。
3. **播放设置**：首屏直接显示画质与 HDR，画质旁保留简短建议，不再重复摘要。删除快捷键帮助。高级选项保留播放结束、截图、配置目录及打开按钮和重置。底部保留安装/保存与返回管理。用同一设置行布局组织选项；移除所有播放硬件检测、显示器选择与分辨率输入；删除语种列表控件。HDR 默认自动，同组可显式覆盖；音轨和字幕采用固定默认值，具体见 [播放默认值方案](playback-defaults.md)。
4. **应用设置**：软件语言与外观成组，关于单独成组，诊断和日志清理收进高级。语言/主题/强调色即时反馈；关于保留仓库、版本、版权及第三方许可证。
5. **变更确认**：统一任务标题、影响摘要、目标和按钮顺序。文件清单、配置差异、登记明细按类型展开；冲突和保留内容直接显示。删除首屏 JSON 堆积，保留完整技术详情。正常错误就地显示，不反复弹窗。

状态与动作：未安装 → 安装播放器；仅核心 → 生成配置；就绪 → 查看状态/调整配置；核心损坏 → 修复；支持资产有更新 → 更新；手改冲突 → 查看差异并保留明确覆盖授权；登记失败 → 重试/关闭登记。刷新不自动执行更新或系统写入。

## 业务不变项

遵守 [当前基线](../current.md)：固定目录；配置独立安装；真实文件 mtime；默认集成意图、配置就绪才登记；不改 UserChoice；卸载保留配置和用户数据；所有权/摘要/预览/锁/备份/恢复有效。无向导、路径选择、外部 MPV、历史版迁移、Linux 空适配器、CI/CD 或安装包。
