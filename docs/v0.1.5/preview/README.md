# v0.1.5 交互预览

本目录是独立设计样机。设计审阅已完成，产品现已进入 v0.1.5 实施；此样机仅保留审阅用途，实际行为以产品与本版交接为准。采用已安装的 React / Mantine 9.7.3，不添加运行依赖，不接入 Tauri IPC。

## 打开

在仓库根运行：

```powershell
node docs/v0.1.5/preview/build.mjs
```

产物为仓库 `.local/ui-v015/preview.html`，可直接用 Edge 双击打开，离线运行。所有 JS、CSS 和批准的 MPV SVG 内联，不依赖 CDN。生成产物和截图留在已忽略的 `.local`，本目录提交可再生源文件。

如需在应用内浏览器查看：

```powershell
node docs/v0.1.5/preview/build.mjs --serve
```

访问 `http://127.0.0.1:1515/`。服务器只监听本机，只返回这一份 HTML；终端 Ctrl+C 停止。它不是定时任务或常驻产品服务。

## 建议体验顺序

1. 默认管理页：比较侧栏、组件折叠、配置/系统状态、路径与高级维护。
2. 顶部切“未安装”，点击安装 → 确认 → 生成配置 → 选择画质/HDR → 安装配置。整个过程仅变更内存示例状态。
3. 切“配置手改”，进入配置并保存，查看冲突提示、覆盖授权与变更详情；取消或 Esc 返回。
4. 切“核心损坏”或“系统登记失败”，检查异常提示与操作入口。
5. 设置在左下角；可即时切语言、主题与强调色；顶部也有快捷预览开关。
6. 缩小窗口观察图标侧栏和控件换行；用 Tab / Enter 检查导航及提示。

顶部场景栏不属于产品。打开文件夹、许可与诊断按钮只显示模拟提示，不启动真实程序。版本、时间、文件差异均为样例；高级配置只展示代表性控件，产品保留其余已批准设置、恢复/清理和来源查看功能，语种排序按新决定移出 GUI。系统跟随选项保留在方案中，本预览只演示手动主题/语言。状态选择器也不代表所有事务失败路径已模拟。

2026-10-22 审阅调整：导航改为“播放器 / 播放设置 / 应用设置”，英文为 Player / Playback / App settings。页面使用 Mantine fade-up（200 ms），折叠 180 ms，弹窗 fade（160/120 ms），提示 fade（120/90 ms）。系统减少动态效果时直接呈现；无额外动画开关或依赖。重新构建后刷新本机页面即可读取新预览。

后续审阅调整：HDR 默认自动，与画质同组提供自动/强制开启/关闭（SDR）；音轨和字幕语种控件删除，采用汉语→日语→英语→西班牙语默认顺序。实际拟生成代码及标签依据见 [播放默认值](../playback-defaults.md)。预览不播放媒体，不能作为真实选轨验收。

最新审阅调整：删除示例设备/重新检测行及显示器相关文案；默认均衡，首屏画质选择旁显示当前档位建议。HDR 强制开启时显示系统 HDR/显示器使用条件，不模拟硬件检测或阻止保存。产品检测代码的删除清单见 [播放默认值](../playback-defaults.md)。

图标复用产品 MPV SVG；导航使用 Windows 已有 Segoe Fluent Icons / MDL2 字体。Linux 交付时需再选可分发的线性图标资产，不能依赖 Windows 私有字形；当前不新增图标库。浏览器用中性纯色背景，不能证明真实 Mica、原生标题栏或高 DPI 效果。
