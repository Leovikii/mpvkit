# v0.1.1 实现与本机验证

日期：2026-10-21。用户已批准整版实施。实现与本机可执行验证完成。完整公开发布状态仍为 releaseReady=false。

## 实现

- 以 Mantine 独立页面替代长表单：四步初装、日常状态/播放设置/组件/集成/维护/设置。播放器常显、增强组件折叠；操作进度、取消、预览和错误保留。
- 无组件不能进入设置或登记；只读启动聚合文件摘要、播放器、增强、配置、登记和恢复状态。已完成环境直接进入状态页，组件丢失不伪装健康。
- settings v2 保留旧覆盖与 user.conf，支持目标显示器/手动分辨率、三档、HDR 三态及音轨/字幕语言顺序。当前窗口输出优先、主屏后备，检测不覆盖手选档位。
- 应用设置独立持久化，简中/英文按系统首选语种匹配；支持明暗、四种强调色与跟随系统、Mica/纯色，设置含关于与本地许可。
- 采用用户提供的 MPV SVG 原始路径/颜色，无底框；转换 Windows 多尺寸 ICO。稳定 helper 和八份许可资源进入同一部署事务，原 EXE 删除后保留启动及保存入口。
- 目录不可达时可明确预览后重选，原目录/登记保留；可访问且仍登记的环境继续禁止直接切换。外部 MPV 在重启与组件更新中保持选择。

## 验证结果

- 普通后端：61 通过，6 显式真实入口默认忽略。完整入口首轮 66 通过、1 失败；失败为误选早期 PQ 媒体夹具（文件内元数据为 bt.1886）。改用既有通过的 05b4…82c1 PQ 样本，保持断言重跑媒体矩阵，1 通过，196.26 秒。合计 67 个后端测试均有通过记录，不声称首轮一次全绿。
- 前端：TypeScript/生产构建通过；中英文同键、占位符和系统语言匹配 2 项通过。
- 真实参数：合成媒体含三音轨、默认/强制字幕，6 项真实 MPV 用例通过（语言顺序、无匹配回退、强制字幕匹配、HDR 参数值）。该探针 vo=null，只验证轨道与参数接受，不验证 HDR 画面。脚本为 scripts/test-media-preferences.mjs。
- 原生 WebView2：三组分次通过：主旅程 202.31 秒（mpvkit-v011-VfKyS7）；旧版/外部播放器迁移 58.85 秒（mpvkit-v011-legacy-aNn1Sy）；外观/失效目标 7.15 秒（mpvkit-v011-appearance-FAzvIM，仅纯色/失焦与语种路径）。最后新增 externalMpv 字段后针对性重跑旧版旅程及两个 setup 测试通过；未无故重复其他已通过的后端测试。
- 构建：调试、Release、NSIS 已构建，最终身份见下表及 artifacts.json。Release CLI 保存也在隔离根验证通过。321 包/567 份许可材料检查通过，无缺失原文；包列表与 v0.1.0 相同，只更新输入摘要及版本标题，许可证不变。八份暂存分发资源摘要与源文件相同。

## 保留的验收边界

当前 Windows 11 build 26200、DPI 192（200%）。运行器未能使窗口成为前台，DWM 读取为纯色 backdrop=1；这验证失焦/纯色路径，不能称 Mica 活动态已通过。computer-use 初始化两次超时，未取得额外原生截图。原生文件选择器取消、打开目录的桌面操作、Snap/系统菜单/屏幕阅读器、多屏切换、100%/150% 实际 DPI 与活动态 Mica、透明开关/节电/高对比度/远程切换仍需可交互桌面补验。

真实媒体矩阵验证本机 gpu-next、D3D11VA、三档及缩略图，不证明实体 HDR 色彩/亮度、目标设备画质或功耗。真实 Windows 安装/升级/卸载、资源管理器打开方式、WebView2 缺失路径与两类目标设备，连同旧版完整来源/适用材料缺口继续保留；参见 v0.1.0 验收台账。Linux 没有实现或测试。
