# 原生标题栏与启动 Mica 修复

日期：2026-10-21。用户授权依据前一轮调查实施修复，版本保持 0.1.1。

## 实现

- 窗口默认隐藏，Rust setup 先初始化主题、DWM 材质及客户区背景，再显示窗口；不再等待 React boot 才设置原生外观。
- 新增 platform/appearance.rs，Windows API 集中在平台模块；commands 仅转调。直接检查 DWM HRESULT 并读回 SYSTEMBACKDROP_TYPE，绕过 Tauri effects 不传回底层错误的问题。
- 支持条件满足时保留 MAINWINDOW 材质配置，不因输入焦点、失焦或最小化主动卸载。原生 Focused/ThemeChanged 事件同步，15 秒复核系统透明/供电等策略；前端接收 appearance-changed，不再混用网页 focus/blur 作为原生事件。
- Mica 时恢复系统标题栏/文字色，延伸 DWM frame，WebView 与壳层露出系统材质；纯色回退同步标题栏与客户区明暗颜色。高对比度用系统背景及 forced-colors。旧 Windows 不支持 caption color API 时保留系统标题栏，不能宣称所有旧版本都可强制同色。
- API 失败输出阶段及 HRESULT；材质布尔值只表示 DWM 接受并读回 MAINWINDOW，不把它宣称为所有系统策略/壁纸下都必然呈现纹理。
- 仅给本地主管理窗口增加事件 listen/unlisten 权限，未允许前端 emit。windows-sys 增加已有 Win32_Graphics_Dwm 功能，无新依赖/升级，锁文件不变；许可清单仅刷新 Cargo.toml 输入摘要，321 包/567 份材料不变。

## 调试中排除的问题

初轮编译缺少 GDI 系统颜色导入、正式构建含测试专用未使用导入，均修正。初轮测试试图读取 CAPTION_COLOR，官方定义其仅供设置，改为检查设置 HRESULT；SYSTEMBACKDROP_TYPE 支持读回并继续强断言。最小化测试首次误用 Process.MainWindowHandle，拿到进程内辅助窗口；诊断器现在固定主窗口句柄并验证所属 PID，未删除材质断言，完整复测通过。

官方 API 依据：[DWMWINDOWATTRIBUTE](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)，当日核对 caption/text 为只写、system backdrop 可读写及支持版本。源码依据为已锁定的 Tauri/Tao/window-vibrancy 实现，见[调查](2026-10-21-mica-investigation.md)。
