# 手动体验清单（历史入口）

2026-10-22 更新。请使用当前构建的单 EXE，不再使用 v0.1.1 临时产物；构建命令见 [README](../../README.md)。当前版本/未完成项见[开发基线](../current.md)。

可按需体验：窗口首帧/明暗/失焦材质、640×600 与 DPI 缩放、键盘/焦点、取消原生选择器、中文路径、打开 portable_config、屏幕/GPU 检测、真实视频/轨道与字体。HDR/高刷/功耗需相应设备，不能把静态截图当实际结果。

真实“打开方式”登记及资源管理器调用只在隔离 Windows 或用户明确指定目标验证；普通测试不得修改开发者真实默认应用、配置和注册表。正式发布前禁止安装包与安装器测试。

本页仅保留持续有效的体验入口；下一版新增检查见 [v0.1.4 方案](../v0.1.4/plan.md)。
