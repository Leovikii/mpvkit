# v0.1.1 手动体验清单

当前实现和本机自动测试已完成。下面是直接操作更方便、或需要相应系统/设备的补验，不要求重跑已通过的组件下载和后端回归。测试版为 .local/test-build/MpvKit_0.1.1_x64-test.exe，需 WebView2；详细证据见[实现记录](evidence/2026-10-21-implementation.md)。

## 你现在方便检查的项目

1. **窗口与 Mica**：背景自动选择，无需设置；在设置中分别切换浅色/深色，点击窗口使其活动，再切到其他窗口。检查标题栏、侧栏和内容区是否清楚、有无黑块/闪烁；失焦视觉由系统处理，应用保持 Mica 配置。本轮已取得本机前台明暗截图并核验 backdrop=2，黑色独立顶栏已消失；仍需其他主题壁纸、DPI 与系统策略组合验证。
2. **系统对话框**：安装位置展开“高级选项”，勾选“自定义安装目录”后点击“浏览”，先取消，确认输入路径不变；再选择新建的测试目录。安装后点击“打开配置目录”，确认打开的是当前环境的 config 或直接配置目录。媒体选择器也检查取消和中文路径。
3. **窗口操作与可读性**：缩到 640×600、最大化、拖动、贴靠；长页面只滚动内容区，标题和侧栏保持。若你使用不同缩放或屏幕阅读器，检查按钮名称、焦点和正文可读性。键盘 Tab、Enter、Escape、弹窗焦点限制和关闭后焦点返回已自动通过。
4. **设备与实际播放**：检查所选屏幕、分辨率和 GPU 是否对应当前设备；如有多屏，将窗口移到另一屏后重新检测。HDR 只在具备 HDR 输出且系统已开启时验证画面；否则保持自动或关闭即可。自动测试已经验证参数和轨道选择，未证明真实 HDR 色彩/亮度或画质收益。
5. **使用感受**：重点看步骤是否自然、常用操作是否好找、文字是否过长、图标在深浅主题是否清楚。反馈“页面/操作 → 实际结果 → 期望结果”即可，不需要重新描述整套方案。

## 需要隔离 Windows 或专用设备

- NSIS 安装、升级、卸载，以及缺失 WebView2 时的引导。
- 资源管理器真实“打开方式”、Windows 默认应用入口与登记移除。自动测试使用私有登记后端，没有改开发者的默认应用；这类补验放在隔离 Windows 或你明确指定的测试环境。
- 系统透明效果、高对比度、节电/远程会话变化，以及多 DPI 切换。
- 两类目标设备的 HDR、画质与功耗；没有条件的项目保持未验证。
