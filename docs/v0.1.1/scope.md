# v0.1.1 版本范围与开发方案

更新日期：2026-10-21。状态：已实现，本机自动化验证完成；保留边界见实施计划。本文依据用户本轮要求制定；[v0.1.0](../v0.1.0/plan.md)主要功能代码已实现，其完整来源、系统和设备验收缺口继续保留。

执行授权：用户已批准整版方案并要求实现及前后端交互测试；当前正式应用已接入实际业务。早期模拟预览仅作为历史设计稿。

## 版本目标

把堆叠在单个长页面中的管理工具重构为 Windows 桌面应用体验：首次运行只完成安装引导，完成后直接进入状态首页，日常设置和维护通过侧栏切换。

v0.1.1 仍只支持 Windows x64。Linux 调整为后续独立版本，版本号与日期另定；这覆盖旧文档“下一版本接入 Linux”的安排。沿用 Tauri 2、React、TypeScript、Rust 和 Mantine 9.7.3，不迁移到原生 WinUI 3；参考 Windows/WinUI 3 的导航、层级、间距、设置行及反馈方式。工具链、固定组件及许可证不因界面重构升级。

## 推荐主流程

启动检查 → ①安装位置 → ②安装组件 → ③播放设置 → ④系统集成 → 状态首页。Windows 第 4 步的页面标题为“添加到打开方式”。

- 启动检查是短暂加载状态，不额外设计欢迎页或要求用户点一次“开始”。
- 已验证的管理环境跳过已完成阶段；不能因为有标记文件或用户曾点“完成”就绕过实际核验。
- 新安装先把 MPV、uosc、thumbfast 和基础配置部署为可用环境，再设置偏好，最后登记系统打开方式。这些是有各自预览和恢复边界的阶段，不伪装成一次跨文件、注册表的原子安装。
- 没有可用 MPV 时只能选目录、下载、查看错误或恢复，不能进入播放偏好、系统集成和正常状态页。
- 当前标准组件组合包含 uosc 和 thumbfast；首次引导须全部就绪。已完成环境后来丢失可选脚本，沿用既有基础播放降级能力，在状态页提示修复，不谎报完整健康。
- Windows 打开方式登记是正常引导的最后必需步骤；“设为默认播放器”由用户在 Windows 设置中选择，不作为完成门槛。用户退出引导时保留已完成安装，下次从未完成阶段继续；不另加绕过 MPV 或系统登记的“跳过并完成”。

## 默认目录和外部安装

推荐根目录由 Windows Known Folder API 取得 LocalAppData 后追加 MpvKit，界面显示实际绝对路径；文档简写为 `%LOCALAPPDATA%\MpvKit`。沿用 runtime、config、state、cache、.mpvkit 的实际布局。不要另建一个名称相近的默认安装根。

手动选择首先识别“已有 MpvKit 管理根”；目录非空但无有效归属时，不自动接管。默认引导推荐选择新的独立目录。保留“使用已有 MPV”高级入口：用户明确选择可信程序并完成兼容检查后，可部署独立配置和必要脚本，播放器继续为外部所有，不被更新或卸载。只有 mpv.exe 或无效标记都不满足完整环境就绪条件。

不再显示“直接使用此文件夹存放配置”。已有直接配置布局自动识别并保留，继续使用逐文件预览、备份和冲突检查；新目录统一使用 runtime/config 子目录。单次只管理一个活动目标，不新增多实例管理仪表盘或自动搬迁。

## 设置范围与默认值

- 常用设置限定为目标显示器/分辨率、画质档位、HDR 策略、音轨语言优先级、字幕语言优先级。初始化完成后也可在“播放偏好”页调整。
- 屏幕检测是配置建议依据；手动分辨率是播放目标参考值，不改变 Windows 显示模式，也不强制拉伸视频或把播放器窗口设为该大小。
- HDR 用“自动（推荐）/开启 HDR 输出/关闭 HDR 输出，映射到 SDR”表达三态意图。系统 HDR 状态与播放器偏好分开显示，不自动切换 Windows HDR。目标构建语义和真实输出验证属于实施任务，不能先画一个无实际作用的开关。
- 默认自动检测并形成建议；信息不完整时使用均衡，电池/节电状态建议省电。GPU 和分辨率参与适配与限制判断；未经实测不按型号字符串给显卡打分或自动切到高画质。
- 语言默认“遵循媒体默认轨道”，允许用户为两类轨道分别选择有顺序的语言列表；不根据中文 UI 擅自认定用户偏好中文配音，也不把字幕语言偏好等同于强制开启字幕。
- 新安装沿用现有基础值：字幕字号 38、OSD 字号 30、启动音量 100、硬解 auto-safe；数值为当前配置基线，不宣称是每台设备最优。旧版用户已保存的覆盖不重置。更改这些基线须另有依据。
- 提供“打开配置目录”按钮，说明自定义放到 user.conf；不增加内嵌配置编辑器，不解析任意手写 MPV 配置。

## 不在本版新增

原生 WinUI/XAML 重写、Acrylic/Mica Alt、完全自绘窗口按钮、Linux 适配、媒体库、内嵌播放器、显卡评分库、后台跑分、全参数 GUI、自动改系统分辨率/HDR/UserChoice、自动更新服务及远程组件目录。

现有更新、恢复、卸载、诊断、日志清理、播放中档位切换和 GUI 关闭后的偏好保存继续保留；只是迁入合适页面，不能因简化引导而删除能力。

## 完成边界

当前应用版本为 0.1.1，优先交付可直接运行的单 EXE 测试版，运行依赖和系统集成产生的本地文件需明确说明；“单 EXE 测试版”不意味着组件或数据都嵌在 EXE，也不代表公开分发许可已完成。

新版本不能用界面验收替代旧版遗留来源、系统、设备门槛；releaseReady 只有在全部适用门槛有证据后才可调整。本方案本身不授权提交、推送、发布或改开发者真实系统登记。
