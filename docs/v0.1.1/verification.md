# v0.1.1 验证要求

更新日期：2026-10-21。状态：验收矩阵；实际本机结果与保留缺口见 [本轮证据](evidence/2026-10-21-implementation.md)。继承[v0.1.0 验证要求](../v0.1.0/verification.md)，历史测试只证明原实现，不自动覆盖新界面和状态流程。

## 必须覆盖的风险

| ID | 场景 | 预期与证据 |
| --- | --- | --- |
| G01 | 全新根目录、无 MPV，点击未来步骤或直接调用设置/登记命令 | UI 与后端均拒绝继续；不写真实系统；可选目录与下载 |
| G02 | 有 owner 标记但无清单、伪造成功标记、缺失/改变 runtime 文件、未知 schema | 不执行未经核验程序、不标成功，不自动覆盖；返回具体阻止原因 |
| G03 | 默认根、自选中文/空格路径、非空无归属目录、旧直接布局 | 新安装自定义默认关闭；同路径无确认且不写目标；实际切换需确认；取消不写；取消自定义回默认；已有布局自动保留；替换必须预览备份 |
| G04 | 不可达目标、网络盘/reparse point、权限拒绝、设备移除 | 有界返回，可重选/重试；不递归扫描，不将失败改为未安装并自动写入 |
| G05 | 下载失败/取消、摘要不符、安全解包失败、组件缺失 | 不开放下一步；旧安装不变；错误就地反馈；按真实阶段显示进度 |
| G06 | 安装中断、配置提交后退出、登记中断、进度记录写失败 | 下次恢复优先；已提交阶段不重复下载；进度记录不能掩盖真实事务状态 |
| G07 | 预览过期、预览后文件/目标/注册值改变、双实例、迟到响应 | 拒绝旧计划；新目标 UI 不显示旧结果；不跨目录写入 |
| G08 | 设置 v1 迁移、已有字号/音量覆盖、旧全局档位、user.conf | 旧意图和文件保留；新增字段默认值明确；迁移有备份；未知版本不覆写 |
| G09 | 多屏、主屏切换、DPI 变化、GPU/输出关联缺失、检测全部未知 | 屏幕身份与高级色彩不串配；保守推荐；手动覆盖不被检测重置 |
| G10 | 三档、HDR 三态、语言优先级含重复/无效/无匹配语言 | 后端校验、配置生成和真实轨道选择一致；档位切换不覆盖独立 HDR/语言意图 |
| G11 | 打开配置目录、取消文件/目录对话框、自选媒体 | 仅当前合法目标；取消无修改；中文/特殊字符使用独立 argv；user.conf 不被覆盖 |
| G12 | Windows 登记存在但实际值被其他应用更改、入口丢失 | 显示登记失效；修复先预览，不覆盖外部修改；不宣称已成为默认应用 |
| G13 | 单 EXE 稳定入口、原测试 EXE 移动/删除、GUI 关闭、helper 被占用/改动 | 系统启动与全局保存仍使用受管理入口；冲突拒绝；不执行变化后的文件 |
| G14 | 已完成环境再次启动、旧完整环境升级、可选脚本丢失 | 健康环境直达状态；新偏好可后改；脚本降级明确，核心损坏则阻止播放 |
| G15 | 目录切换、恢复上一版本、清理、移除环境与自身卸载 | 继续保护用户数据、外部 MPV、未知/修改文件、备份和他方登记 |
| G16 | 播放器/增强分组、折叠中下载失败、部分扩展缺失 | 两组状态与逐项结果一致；失败显式提示并展开；折叠不绕过必装门槛、不改变事务或所有权 |
| G17 | 系统 zh-CN/zh-Hans/zh-SG/en-*、繁体/未知语言、有序后备、手动切换 | 按匹配规则选简中/英文；不假称支持繁体；手选优先、缺键/占位符检查通过；不改变媒体语言 |
| G18 | 设置中切语言/明暗/强调色，下载或表单编辑中切换，保存失败/未知 schema | 草稿、焦点、操作 ID 与目标保持；应用设置与 MPV 配置分离，保存失败如实提示，重启按已保存选择恢复 |
| G19 | Windows 11 22621+ 的真实 Mica、首帧、原生标题栏/WebView2/控件表面 | 底层材质真实可见、内容清晰；单窗口一次效果；拖动/缩放/Snap/系统菜单/多 DPI 正常，不能用浏览器渐变替代 |
| G20 | 旧纯色偏好自动迁入、不支持系统、透明关闭、节电、高对比度、失焦、远程会话及恢复 | 不以失焦或最小化卸载 Mica；按实际系统/平台策略纯色回退；不中断业务，无黑白闪屏或透明孔洞；高对比度覆盖强调色，恢复后自动重新评估材质 |
| G21 | 设置内关于、版本、仓库地址、版权/第三方声明 | 单一设置入口，无重复关于侧栏项；版本来源真实，链接经确认，长许可可访问且不擅自翻译原文 |
| G22 | 当前 Windows 步骤及未来可省略的平台步骤模型 | 稳定 ID 与可见计数分开；无组件仍不能继续，不渲染空平台页；本轮仅审阅 Linux 契约，不宣称 Linux 已实现/测试 |

不要为纯展示组件逐个写镜像测试。后端测试集中状态分流、前置条件、迁移、推荐和恢复风险；端到端测试验证用户真实完成任务的路径。

## 原生交互与视觉验收

以下五类旅程由五组原生测试和后端破坏场景测试交叉覆盖；需要真实桌面/设备的项目另记未验证：

1. 新目录 → 下载/预览/部署 → 自动推荐并修改语言 → 应用 → 登记 → 完成 → 重启直达状态页。
2. 有效旧环境 → 识别/迁移 → 保留原设置与 user.conf → 状态页调整新偏好。
3. 无效标记/缺 MPV → 禁止跳步 → 修复 → 从正确步骤继续。
4. 下载失败或取消、设置冲突、登记失败 → 就地恢复/重试，不丢已提交结果。
5. 日常打开媒体、切换三档与保存、组件更新、目录切换、恢复/移除及诊断，确保原能力没有被藏掉或删除。

截图至少保留四个引导步骤、增强组展开/折叠及失败、健康/故障状态页、设置页（语言/外观/关于）和一个维护预览。简体中文与英文均走完关键流程；核对英文长按钮、数字/计数与辅助技术标签。检查浅色/深色、高对比度、键盘全流程、焦点归还、屏幕阅读器名称/状态、减少动画；窗口 1040×760 与 640×600、100%/150%/200% DPI 或等效可用工作区，长中文路径不横向溢出，底部主操作不遮挡错误。记录操作系统、DPI、客户端实际尺寸和 WebView2 版本，不拿浏览器静态页截图代替原生通过。

浏览器预览只能使用明确标注的只读示例数据；不显示“本机已安装/已登记”的假状态。原生测试改用页面/步骤定位，复用既有 Playwright 入口和隔离根；不创建另一套测试框架。

## 参数、播放和 Windows 验证

- 参数：对固定 MPV 提交核对语言/HDR 选项语义，再运行真实构建。语言用带多个音轨/字幕轨道和默认/强制标志的受控样本，覆盖无匹配回退。
- HDR：SDR 屏、HDR 支持但 Windows 关闭、Windows 开启、未知输出分别核验自动/开启/关闭策略；实际 HDR 色彩与亮度效果需要实体输出链。未具备环境则保持未验证，不把命令接受参数视为效果通过。
- 推荐：至少覆盖现有 4K 台式机与 1440p 核显本目标；记录分辨率、适配器/输出对应、供电、推荐理由和用户覆盖。功耗及高画质收益继续按旧版真实测量要求验收。
- 集成：隔离文件后端/私有蜂巢先验证恢复；真实 HKCU、资源管理器打开、系统默认应用入口、安装/卸载与 WebView2 缺失路径在隔离 Windows 或明确指定目标验收。不能自动改开发者真实登记、配置或默认播放器。
- 稳定入口：分别验证安装包模式与单 EXE 模式；原 EXE 移动、入口更新失败、文件占用、卸载和 GUI 关闭后偏好保存必须有记录。

## 本轮新增专项验收

- 文案：按界面文案表审阅正常/空/加载/失败/确认状态；用户无须理解内部事务或归属字段即可操作，必要的覆盖/移除风险仍明确。英文资源不能存在未翻译键或中文 fallback；用户数据、上游名称、版权原文不算翻译遗漏。
- 应用偏好：无 MPV 时也能进设置改语言/主题；原生主题、Mica 与 Mantine 配色一致；system 模式跟随系统变化，手选不变；恢复 MPV 配置或切目标不重置应用设置。
- Mica：先检查锁定库实际调用路径及权限，再在 Windows 11 22621+ 实机验收浅/深主题、壁纸变化、活动/失焦、透明开关、节电和高对比度；记录实际回退由谁处理。较早构建/不支持环境验证纯色即可，不把材质不支持当安装失败。不擅自更改开发者真实系统设置，相关场景在隔离或明确指定环境执行。
- 关于：从构建/资源读取版本及许可证；当前仓库未配置 remote，未确认仓库 URL 时不得提供猜测链接。离线仍可读本地声明，外链只响应用户点击。
- 图标：与用户提供的 SVG 核对 path/viewBox/填色；正式实现核对多尺寸 Windows 图标、DPI、深浅主题和可访问名称；来源/许可记录纳入发布核对。
- 平台边界：Linux 菜单/MIME 方案仅做设计一致性检查，本版不测试不存在的 Linux 实现。

## 执行与记录

每个代码切片执行相关检查；集成阶段按现有命令完成一次完整回归，不为纯文档改动构建或重跑业务测试：

~~~powershell
pnpm build
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml --locked --all-targets -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml --locked
pnpm tauri build --debug --no-bundle
pnpm test:e2e
~~~

有明确环境与授权后运行既有真实入口；依赖/资源发生变化时补做许可收集检查和构建资源核对。每份结果记载输入版本、命令、环境、实际通过/失败/跳过、证据位置和未验证部分。截图/日志默认留在本机，公开引用前处理敏感路径。
