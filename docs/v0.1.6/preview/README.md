建议依次尝试：

1. 未安装：选择高画质/HDR，预览文件；点击“安装并保存配置”，观察先安装后保存。
2. 未安装：编辑草稿 → “仅安装组件” → 切页返回 → 确认草稿保留 → “保存配置”。
3. 顶部选择“安装失败演示”或“保存失败演示”，执行后查看提示并重试。
4. 选择“配置手改”，在保存预览中检查覆盖授权；取消不改变状态。
5. 切英文、深色，缩窄窗口，滚动高级内容，确认底部操作始终可达。

预览工具栏只为演示场景，不进入产品。应用设置里的系统跟随、完整许可/诊断、完整维护功能等仅在真实产品实现，本预览不把模拟成功当作实机验收。Mica、屏幕阅读器、真实 DPI 等仍需原生测试。
